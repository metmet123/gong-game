# 예산 퍼즐 확장 작업본

`index.html`을 브라우저에서 열면 기존 게임의 연습실에서 두 퍼즐을 고를 수 있다. 배포 통합 기준은 main 0376a96이다. 두 퍼즐이 정식 id it/budget으로 옮겨져 각각15문제씩의 하·중·상이 추가되어 있었다. 이 기존90문제를 전부 보존하고 승인한 업무형12개를 추가했다. 각각 하15·중18·상18, 총102문제다. 업무형 문제는 중·상 지도16~18번이다.

| 퍼즐 | 중 | 상 |
|---|---|---|
| 정산표 | 중복 증빙 / 과목 대조 / 승인 마감 | 최신 승인본+미승인 제외 / 지출결의와 지급·공제 구분 / 연도·재원과 결산 대조 |
| 예산표 | 사용 과목 / 사업비 한도+재원 / 사업기간·재원 도착 | 과목+금액+재원 / 재원+시기+승인 / 재원+시기+선후 사업2쌍 |

정산은 합계를 맞추며 증빙을 확인하는 퍼즐, 예산표는 가능한 자리와 사업 간 관계를 좁히는 퍼즐이다. 새 규칙은 첫 진입 안내와 화면, 도움말에서 읽을 수 있다. 증빙은 “증빙 읽기” 모드에서 답안을 바꾸지 않고 비교한다. 예산표의 잠금 칸을 누르면 막힌 이유를 보여준다.

## 빌드·검사

작업 폴더에서 Node.js와 Python으로 실행한다. 빌드 기준 커밋이 로컬 Git에 있어야 한다.

```text
node budget/generate.js
node scripts/build-budget.js
node scripts/test-budget.js
python -m http.server 8784 --bind 127.0.0.1
node scripts/browser-budget.js
node scripts/deploy-smoke.js
```

문제 생성은 고정 seed로 동일한 데이터를 만든다. 첫 명령은 데이터를 다시 만들 때만 필요하다. 브라우저 검사는 이 컴퓨터의 Codex 번들 Playwright와 Edge를 사용한다. 다른 환경은 `scripts/browser-budget.js`의 Playwright 경로를 설치 환경에 맞춰 바꾼다. 테스트 중에만 기존 컨트롤러 접근을 열며, 출시 HTML에는 테스트 함수나 정답 버튼을 넣지 않는다. 정답은 기존 퍼즐처럼 확정 힌트용 witness로 포함된다.

게임 주소: https://metmet123.github.io/gong-game/

검토 화면: https://metmet123.github.io/gong-game/budget-review.html

화면 검증 캡처는 `test-results/`에 있다. 승인된 계획의 크림색·녹색과 4×4/5×5 판, 증빙/사업 카드, 월별 합계/예산 묶음, 공통 아래 버튼을 유지했다. 320·375px에서 각 신규 버튼 최소44px, 가로 넘침0을 검사한다. 실제 터치감·풀이 시간·재미는 사용자 확인 대상이다.
