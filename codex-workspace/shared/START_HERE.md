# 공무원키우기 새 세션 시작 안내

공무원키우기 프로젝트 안에서 새 채팅을 시작하면 프로젝트 루트의 AGENTS.md가 공통 지침 shared/AGENTS.md를 읽도록 안내한다. 긴 시작 지시문을 채팅마다 붙여넣을 필요가 없다.

## 새 채팅에서 할 일

공무원키우기 프로젝트를 선택해 새 채팅을 만들고 원하는 작업만 요청한다. 예를 들어 “주민센터의 전입신고 저장 기능을 이어서 구현해줘”처럼 대상 섹션과 작업을 적으면 된다. 새 세션은 공통 지침에 따라 담당 폴더와 최신 상태를 확인한다.

새 채팅의 기본 작업 폴더는 공무원키우기 프로젝트 루트로 유지한다. 다른 프로젝트나 폴더에서 만든 채팅에 이 프로젝트 지침이 자동 적용된다고 전제하지 않는다. shared만 별도의 프로젝트로 등록할 필요는 없다.

## 섹션 폴더에서 직접 시작할 때

각 섹션의 AGENTS에는 담당 범위와 공통 지침을 읽는 연결만 둔다. 프로젝트 루트가 자동 탐색되지 않는 환경에서도 해당 섹션의 진입점을 통해 같은 공통 지침을 읽는다. 루트에서 실행하는 세션은 공통 지침의 담당 판단에 따라 섹션 지침을 직접 읽는다.

## 기존 실행 중인 채팅

이미 실행 중인 채팅에 새 지침이 즉시 다시 로드되었다고 간주하지 않는다. 지금 적용해야 한다면 “프로젝트 AGENTS.md의 최신 지침을 다시 읽고 적용해줘”라고 한 번 알릴 수 있다. 새 세션에는 별도의 지침 복사 절차가 필요 없다.

## 파일별 역할

- AGENTS.md: 새 세션이 읽는 프로젝트 진입점
- shared/AGENTS.md: 공통 작업 규칙의 원본
- 각 섹션의 AGENTS.md: 담당 범위와 섹션별 예외
- shared/PROJECT.md, SPEC.md, OWNERS.md: 공통 맥락, 규격과 파일 담당
- 각 섹션의 STATUS.md와 shared/handoffs/: 최신 작업 상태와 변경 전달

## 공식 안내

[AGENTS 자동 탐색](https://learn.chatgpt.com/docs/agent-configuration/agents-md)과 [프로젝트의 기본 폴더](https://learn.chatgpt.com/docs/projects)에 따라, 새 채팅은 같은 로컬 프로젝트의 기본 폴더에서 시작한다. 새 세션의 자동 지침 로드와 현재 실행 중인 세션의 지침 갱신은 구분한다.
