# 공무원키우기 문서 관리 역할 적용

- 발신: 프로젝트 운영 문서 정리
- 수신: 전체
- 종류: 적용된 변경
- 작업 로그: [공통 운영 기록](../2._WORK_LOG.md)

공통 지침에 전역 문서 관리 규칙과 기존 문서의 역할을 연결했다. [문서 역할과 담당](../DOCUMENTS.md)에서 기존 자료의 경로와 기록 위치를 확인한다. STATUS는 현재 상태와 전달 확인으로 정리했고 상세 완료 기록은 작업 로그로 연결했다.

각 섹션은 다음 작업 전에 공통 지침과 문서 역할을 확인하고, 실제 변경과 검증은 담당 로그에 기록한다. 같은 역할의 문서가 있으면 기존 이름을 유지한다. 확정 명세와 작업 JSON의 완료 상태 및 의존성은 보존한다.

담당 채팅이 확인한 뒤 자기 STATUS의 전달 확인을 갱신한다. 상세 변경과 검증 결과는 위 작업 로그에서 확인한다.
