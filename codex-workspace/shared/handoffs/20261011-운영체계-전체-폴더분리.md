# 공무원키우기 섹션별 작업 체계 적용

- 전달 ID: 20261011-운영체계-전체-폴더분리
- 작성일: 2026-10-11
- 발신: 프로젝트 운영 체계 설정
- 수신: 전체
- 종류: 적용된 변경

확장계획, 주민센터, 생활보장과, 교통행정과에 작업 지침과 상태 파일을 추가했다. shared에는 프로젝트 기준, 파일 담당, 공통 규격, 전달 양식과 채팅별 시작 지시문을 추가했다.

주민센터의 기존 폴더와 자료는 유지했다. 생활보장과의 docs/episodes와 민원봉사과의 docs/chapters/civil_service, 루트 게임의 위치도 유지했다. 실제 소스 이동이나 게임 통합은 수행하지 않았다.

각 채팅은 다음 작업 전에 루트 AGENTS와 자기 AGENTS, shared의 기준 문서를 직접 읽고 STATUS를 최신 작업 상태로 갱신한다. 기존 채팅의 작업 디렉터리는 프로젝트 루트로 유지하며, 담당 하위 폴더를 지침으로 지정한다.

진행 중인 채팅에 메시지를 발송하거나 작업 디렉터리를 변경하지 않았다. 지침을 실제로 읽기 전까지 각 채팅이 적용했다고 간주하지 않는다. 최초 수신 확인을 자기 STATUS에 기록한다.
