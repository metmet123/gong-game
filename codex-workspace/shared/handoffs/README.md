# 공무원키우기 섹션 간 전달 기록

각 섹션은 다른 섹션에 영향을 주는 변경마다 새 Markdown 파일을 만든다. 양식은 `../HANDOFF_TEMPLATE.md`다. 파일명은 `YYYYMMDD-HHMMSS-발신-수신-주제.md`로 정한다. 같은 이름이 이미 있으면 고유한 접미사를 붙이고 덮어쓰지 않는다.

작업 시작 때 자신 또는 전체가 수신자인 기록을 읽고 자기 STATUS의 전달 확인 표와 비교한다. 날짜만으로 처리 여부를 판단하지 않는다. 반영 결과와 보류 사유는 자기 STATUS에 남긴다.

이 폴더는 소통 기록이며 자동 알림 서비스가 아니다. 긴급 변경은 사용자가 담당 채팅에 기록을 확인하도록 알려야 한다.
