## 변경 내용과 이유

기존 전입창구를 유지하고 Orwell 참고 UI를 새 복지상담실에 사용하도록 상세 계획을 작성했다. 계획·별도 시안만 생성했고 게임 구현·공개 배포는 미착수다.

## 수신 섹션에 미치는 영향

주민센터 복지상담실 W03의 생활 상담 의뢰를 생활보장과 담당 역할로 연결하는 구상이다. 기존 생활보장과 공문 A/B/C 퍼즐과 독립이며 해당 파일·규칙은 변경하지 않는다. 기존 나소라 캐릭터 이름·말투를 사용할 경우 담당의 현행 설정 확인이 필요하다.

## 필요한 조치와 완료 조건

캐릭터의 역할과 말투가 현재 계획과 맞는지 다음 작업 시작 때 확인한다. 확인 전 주민센터는 일반 역할명 ‘생활보장과 상담 담당’으로 W03을 완결한다. 새 퍼즐 구현이나 타 부서 소스 변경을 요구하지 않는다.

파일로만 전달하며 다른 채팅에 메시지는 보내지 않았다.
