# 섹션 간 변경 전달 양식

이 양식을 복사해 handoffs 안에 날짜 시각과 발신 수신 섹션이 포함된 새 파일을 만든다. 상세 작업 경과와 검증 이력은 담당 로그를 링크한다.

- 전달 ID: 파일명과 동일
- 작성 시각: YYYY-MM-DD HH:mm:ss +09:00
- 발신: 확장계획 / 주민센터 / 생활보장과 / 교통행정과
- 수신: 해당 섹션 또는 전체
- 종류: 적용된 변경 / 변경 제안 / 협조 요청
- 관련 작업:
- 관련 파일: 프로젝트 루트 기준 상대 경로
- 작업 로그: 실제로 존재하는 담당 로그의 상대 경로와 항목
- 검증 근거: 실제 결과 파일 또는 로그 링크

## 변경 내용과 이유

수신자에게 필요한 변경을 요약하고 적용된 변경과 제안을 구분한다.

## 수신 섹션에 미치는 영향

수정할 데이터, 코드, 화면 또는 작업 순서를 적는다. 저장과 ID가 바뀌면 기존 자료의 호환 방법도 적는다.

## 필요한 조치와 완료 조건

수신자가 할 일, 완료를 확인할 방법과 처리에 영향을 주는 남은 문제만 적는다.

수신자는 자기 STATUS의 전달 확인 표에 확인, 반영 또는 보류를 기록한다. 원본 전달 기록을 수정하지 않는다.
