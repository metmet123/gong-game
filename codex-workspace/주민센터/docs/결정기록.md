## 2026-10-11 · 관계 추론 중심 첫 접수

기존 엔진으로 판정·스냅샷을 만들고 선택적 tutorial 저장 필드로 초안과 완료를 검증한다. 옛 저장의 키·버전은 유지한다. 근거 읽기와 new-head 이유 선택은 이 도입 사건의 완료 조건이며 일반 사례 규칙으로 확장하지 않는다. 실기기·초심자 평가는 미완료이며 공개 배포는 하지 않았다. [구현 계약 및 검증](첫접수_구현검증.md).

## 2026-10-11 · 기존 전입창구 유지와 새 복지상담실 분리

사용자가 기존 전입 버전을 유지하고 새 관계망 UI를 다른 업무에 연결하는 방향을 선택했고, 전입창구 구현→복지상담실 구현의 상세 계획을 요청했다. 기존 전입 UI의 Orwell 전면 교체 계획은 현재 방향으로 사용하지 않는다. 이전 시안과 기록은 보존한다.

전입은 이미 있는 첫 접수·6사례·12방문·저장을 인수하고 보완한다. 복지는 근거와 관계·생활 상황·연결 계획을 판단하는 독립 엔진으로 설계한다. 기존 전입 모델을 새 센터 envelope에 포함하고 독립 저장 키·명시적 가져오기·호스트 저장 확인으로 연결하는 구조를 제안했다. 첫 출시 복지 보상은 센터 기념품이며 본편 XP/포인트는 추가하지 않는다. 새 본편 필드와 캐시 경로 반영은 확장계획 담당 조율 대상이다.

첫 전입 근무 후 개방·따뜻한 생활 이야기·1건 검증 후 총 3건과 화면 수치는 추천 가정·검토 제안이다. 실제 게임 구현·배포로 간주하지 않는다. [상세 명세](전입창구_복지상담실_상세개발계획.md).

## 2026-10-11 · 두 업무 로컬 구현 계약

- 사용자가 확정 계획대로 전입창구부터 단계별 자율 구현과 모바일 검증을 지시했다. 추가 콘텐츠는 W01~W03까지, 새 공개·본편 반영은 별도다.
- 기존 전입 저장 모델·키·보상은 유지하고 새 센터 envelope만 Web Locks 아래 호스트가 저장한다. 전입 v2는 선택적이며 구 독립판/구 embed 경로를 유지한다.
- 부모가 저장한 ack 뒤에만 자식이 저장 완료를 표시한다. 전환은 flush/ack 이후이며 실패 시 화면과 초안을 유지한다. 미지원 환경은 메모리 진행과 JSON 백업이다.
- 센터 가져오기는 명시적 확인과 현재 백업을 거친다. 구 전입 키는 보존한다. 개방 근거 감소 시 기존 복지 기록·초안은 보존·열람하고 새 상담은 잠근다.
- 복지는 주장·근거·현재 시점·동의·연결 계획을 순수 엔진으로 확인한다. 저장 완료 스냅샷도 재검증한다. W01 전화 연락의 두 표현, W02 데이터 기반 확인 대기, W03 두 상담을 동일 엔진에서 지원한다.
- 모바일 근거 목록은 선택창으로 분리해 판단 카드에 중복 표시하지 않는다. PC는 자료/판단 동시 패널이다. 치수는 구현 기준이고 사용자 개별 수치 승인으로 기록하지 않는다.
- 새 복지 보상은 내부 기념품이며 실제 지원 승인·본편 XP/포인트를 추가하지 않는다. 캐릭터 협업은 일반 역할로 독립 구현하고 설정 연결은 담당 확인 뒤 반영한다.
- 기존 최종검사.json은 보존하고 새 전입 인수·센터 결과를 분리했다. 자동검사 통과와 실제 기기/사람 평가·공개/정식 통합을 분리한다.

## 2026-10-11 · 복지 정식 즉시 개방과 난이도별 9건

사용자가 A(처음부터 정식 상담)를 선택하고 상담 다양화·상중하별 여러 건을 지시했다. 전입 첫 근무 후 개방과 3건 상한은 이 지시로 대체한다. 하·중·상 각 3건, 총 9건으로 구현하며 사례는 자유 선택한다. 시간 제한·감점 대신 자료의 시점·도움 범위·두 근거·동의 경계·복수 상담과 순서로 난이도를 구분한다.

기존 3건의 ID·자료·판정·완료 기록을 유지하고 메타데이터만 추가한다. 기존 오답 초안에 저장된 검토 문구도 재검증 계약의 일부라 보존한다. 여러 초안과 비순차 완료를 허용하고 기념품 배열은 데이터 순서로 정규화한다. 답신은 실제 확인 뒤 한 번만 기록하고 복지 근무는 1~10이다. 이전 빌드에서 새 6건 기록을 읽는 역호환은 제공하지 않고 읽지 못한 원본 보호를 유지한다.

새 사례는 실제 법정 자격/지급 판정이 아닌 창작 상담이다. 체험 다시 풀기는 정식 기록을 바꾸지 않는다. 공개와 본편 반영은 별도다. 상세 계약·UI 전후·치수 비교는 [9건 명세](복지상담_난이도9건_명세.md).
