# 본편 연결 계약

기준: 2026-10-11 공개 배포 HTML의 고정 사본. [확인 정보](본편자료/확인.json)에 URL·SHA-256·확인일을 기록했다. build_integrated.py가 원본 해시와 각 연결 지점의 1회 존재를 확인하고 후보를 만든다. upstream 프로젝트 소스·커밋·배포 절차는 미확인이다.

## 보호와 연결 지점

원본 사본은 변경하지 않는다. 후보에서만 본편 저장 키를 gong-game:integration:main:v2로 변경하고, 보상 원장에 rc:visit:M01…M11/M06-return 및 rc:day:1…4를 허용하며, 전입신고 연습을 기존 부서 친밀도 지급에서 제외한다. 추가 adapter는 본편 app IIFE의 마지막에 연결하여 S, Core, Puzzles, CATALOG, FLOORS, openPuzzle, storeDraft, updateHud를 사용한다. 이 이름과 위치가 달라지면 빌드가 실패하도록 고정했다.

별도 순수 모듈을 본편 앱 실행 전에 추가하고, 전입신고 완성 HTML을 sandbox iframe에 담는다. iframe은 allow-scripts/allow-downloads만 사용하며 본편 DOM·localStorage에 직접 접근하지 않는다. parent/child 출처 창과 세션 토큰을 확인해 통신한다.

## 발령·진행·성장

본편 finished 상태에서 정식 발령을 시작한다. finished 이전에는 체험만 열리며 기존 상태를 저장하거나 보상을 지급하지 않는다. 본편 상태의 residentCenter에 독립 챕터 model을 중첩한다. hostActive는 새로고침 후 창구 복원에 사용한다. 돌아가기 버튼은 자식의 대기 중 초안을 먼저 flush한 뒤 본편 복귀를 수행한다.

등록과 보완 안내 모두 각각 한 방문 기록이다. 방문은 taskXP=15/taskP=20, 결산은 leaveP=15로 기존 경제 상수를 사용한다. 총 180XP/300포인트를 지급 원장으로 한 번만 지급한다. 독립 저장·체험·연습에는 이 보상이 없다. 도구·장식·친밀도·기존 업무 기록은 그대로 보존한다. 주민센터 기념품은 중첩 챕터 소유품이며 기존 도구 목록에 혼입하지 않는다.

## 퍼즐 연습 연결

movein을 dept registry와 목록·지도에 등록했다. 하 난이도 M01~M04, 중 M05, 상 M06으로 구성한다. 별도의 신규 퍼즐 UI에서 완료하면 본편 draft에 결과를 전달하고 기존 제출 버튼으로 연습 기록을 남긴다. 전입신고 문서의 확인과 힌트는 자체 규칙을 따르며 본편 별 기록과 성장 보상을 구분한다.

## 저장·백업·오류

전입신고 독립 저장 키는 gong-game:resident-center:v1, 후보 본편 키는 gong-game:integration:main:v2이다. 후보가 배포본 gongmuwon-proto-v1나 구버전 civil-servant-grow-v1를 덮어쓰지 않는다. 기존 배포 저장의 자동 이관은 구현하지 않았다.

model 버전·진행 순서·처리 결과·기념품 근거를 검증하고, 본편 원장 금액과 방문·결산 근거도 검증한다. 본편 쓰기가 실패하면 자식에 실패 응답을 보내 백업 안내를 표시한다. 최초 발령 저장 실패 때도 안내를 표시한다. 저장 실패를 성공으로 표시하지 않는다.

Windows Edge에서 오프라인 단일 파일로 검증했다. 실기기 및 실제 배포 파이프라인 검증은 남은 확인 사항이다. 기존 본편의 저장 구현 전체를 변경하거나 동시 쓰기의 전역 잠금을 추가한 것은 아니다.
