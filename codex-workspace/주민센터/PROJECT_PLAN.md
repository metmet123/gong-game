# 복지상담 우선 · 난이도별 사례 확장

## 목표

전입 선행 없이 정식 복지상담을 시작하고 하·중·상 각 3건, 총 9건을 자유 선택해 플레이한다. 기존 전입과 복지 기록을 보존한다.

## 상태

2026-10-11 · 사용자 A 선택·난이도별 여러 건 지시로 로컬 구현. 최종 자동 검증 164개 통과. 실제 기기·초심자 평가·새 공개·본편은 별도다.

## 완료

2026-10-11 · 이전 두 업무센터·복지 3건 및 복지 우선 배치 완료 이력은 [작업 로그](2._WORK_LOG.md)에 보존한다. 신규 6건·사례철·즉시 개방·복수 초안·비순차 완료·질문/결과 UX 구현.

## 진행

로컬 구현·최종 자동 검증 완료. 실제 기기·사람 평가와 새 공개·본편 조율 대기. 실기기와 사람 평가는 자동 검사로 대체하지 않는다.

## 결정

A 선택으로 이전 전입 첫 근무 후 개방을 대체한다. 시간 제한/감점 대신 판단 쟁점으로 난이도를 구분한다. 기존 W01~03 완료 스냅샷·오답 검토 문구와 전입 저장·보상을 유지한다. UI 치수는 구현 기준이다. [현재 9건 명세](docs/복지상담_난이도9건_명세.md)·[결정](docs/결정기록.md).
