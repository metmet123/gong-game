# 비대사 문구와 진행 맥락 검수

2026-10-11 완료. 1차 표현 검수본을 기준으로 137개 데이터 필드를 추가 수정했다. 처음 원본 대비 누적 변경은 459개 필드다. 숫자는 중복 사용 문장을 포함하는 필드 수다.

문장만 읽지 않고 공개 본편 사본의 결재 문제, 날짜별 업무 목록, 난이도별 문제, 도감 출력 함수, 다음 날 결과 조건, 업적 판정, 분기 재시작 흐름을 대조했다. 원본·사본 목적지가 3일차와 6일차에 다른 것은 기존 퍼즐의 실제 조건이며, 조건을 바꾸지 않고 차이를 설명했다.

## 검증

- 데이터·읽기용 대본 일치 및 구조 검사 PASS: [validation.json](../validation.json).
- 스크립트 6개 문법과 실제 Week 데이터 연결 PASS: [runtime-validation.json](../runtime-validation.json).
- 실제 신문·도감 출력 함수를 메모리 DOM으로 실행: 15일 출근 직후, 협조 미완료·완료, 보조 완료, 2분기 첫날, L3/L6 목적함 대조 PASS: [render-validation.json](render-validation.json).
- 변경 전후 137개 목록: [changes.json](changes.json). 1차 377개 목록은 [language-changes.json](language-changes.json)에 보존.

실제 브라우저·모바일 줄바꿈과 전체 게임 플레이는 미검증이다. 이 결과는 텍스트 출력과 진행 조건 검증이며 전 화면 플레이 완료를 뜻하지 않는다. 공개 사이트는 수정하지 않았다. 최신 후보는 [candidate/index.html](../candidate/index.html).

재현: `python 확장계획/narrative-review/validate.py`, `node 확장계획/narrative-review/check-runtime.cjs`, `node 확장계획/narrative-review/check-context.cjs`. `context-revise.py`는 고정된 1차 완료본에서 재생성하므로 이후 변경이 생기면 먼저 합쳐야 한다. `revise.py`에는 2차 작업을 덮어쓰지 않는 보호 장치를 추가했다.
