# 공무원키우기 프로젝트 지침 진입점

이 프로젝트에서 작업을 시작할 때 `shared/AGENTS.md`를 최신 파일에서 읽고 적용한다. 공통 작업 규칙의 원본은 그 파일 한 곳이다. 공통 규칙을 섹션별 지침이나 채팅별 시작 문장으로 복제하지 않는다.

새 세션도 첫 요청의 작업 내용과 경로에 따라 담당 섹션을 판단하고, 공통 지침에 정해진 상태 확인과 전달 절차를 수행한다. 담당이 정해졌으면 해당 섹션의 `AGENTS.md`와 `STATUS.md`를 직접 읽는다.

경로는 이 파일이 있는 프로젝트 루트를 기준으로 해석한다. 이 진입점과 공통 지침의 내용이 바뀌었으면 다음 작업 시작 때 다시 읽는다.
