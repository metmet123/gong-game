## 3. 소프트웨어 결합 평가

`GameCore`는 DOM 없는 함수 집합으로 가장 먼저 보존할 자산이다. 다만 타입 정의/생성/판정/일차/경제/구매/저장 검증을 한 closure에 넣어 책임이 넓다. `scene-controller`는 전역 state·active·모달·렌더·보상·save 호출을 함께 묶는다. `scene-art`는 `state`, `active`, `pendingFor`를 직접 읽어 그림과 업무 결합이 강하다. `workshop`은 기본 문자열 markup을 후처리한다.

`build_scene.py`는 `game-app.js` 함수 구간을 문자열 index로 잘라 삽입/치환한 후 3개 HTML을 쓴다. 함수명/문구 변경에 취약하고 모듈 경계가 아니다. 이번에는 실행하지 않는다. 이후 기존 순수 규칙을 테스트로 동결하고 새 `src/` 모듈/새 `dist/` 경로를 만들어 차례로 교체한다. 기존 파일은 회귀 기준으로 보관한다.
