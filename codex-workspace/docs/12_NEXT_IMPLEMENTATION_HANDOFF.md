## 작업 보고와 금지사항

TASK 기록은 id·수정파일·자동실행명령/결과·수동환경/절차·미검증·체험빌드·다음TASK를 남긴다. planned→in_progress→done은 실제 DoD 후에만 갱신한다. 실패면 초안·마지막정상save·원본사본을 보존하고 차단 원인을 분리한다. 원본해시를 마지막에 재검사한다.

금지: 원본 덮어쓰기, 실제세이브로 시험, 현실 인물/번호/민감문서, 타사그림/문제/코드 복제, 외부네트워크 필수화, 유료API 기본도입, 고정답과 좌표 일치 판정, 반응속도/관계로 핵심해금 제한, 문서검증을 신규게임완성으로 보고하기. 타과는 P9 안정화 전 착수하지 않는다.
