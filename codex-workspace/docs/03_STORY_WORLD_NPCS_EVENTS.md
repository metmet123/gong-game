# 세계관·15일·인물·사건

설계 제안 [D]. 모서리구청은 실재 구청이 아니다. 생활보장과 명칭/원본 공간만 개인용 배치 참고로 사용하며 인물·전화·민원 내용은 전부 가상이다. 사람의 빈곤·질병·장애를 웃음 소재로 쓰지 않는다. 웃음은 ‘최종 파일이 셋’, ‘방금 바뀐 서식’, ‘금일 중 제출인데 회신은 익일’에서 만든다.

## 플래그와 되돌아오는 결과 12개

이벤트는 `id,day,trigger,conditions,choices,effects,callbackDay,callbackVariant,onceKey` 데이터. `effects`는 허용된 enum을 사용하고 임의 JavaScript/eval 금지. 예:

```json
{"id":"ev_final_label","day":2,"trigger":"afterTask:sort",
 "choices":[{"id":"share","text":"승인본 링크를 공유한다","effects":[{"set":"choice.final","value":"share"}]},
            {"id":"personal","text":"내 메모에 먼저 적는다","effects":[{"set":"choice.final","value":"personal"}]}],
 "callbackDay":3,"onceKey":"campaign1:ev_final_label"}
```

|입력/선택 플래그|다음 날/후속 결과|효과/복구|
|---|---|---|
|D1 `review.checkedUnit` 또는 assisted|D2 기사 ‘단위 확인해서 정정 생략’/‘확인표를 함께 첨부’|기사만 다름, 승인본도감 동일|
|D2 `choice.final=share/personal`|D3 재훈 공용 링크/개인 메모 대사|메모 spritevariant, 선택을 나중에 공유할 수 있음|
|D3 `call.memoComplete`|D4 회신제때/동료 확인전화|optional 회신1→0턴 단축, main은무료회신폴백|
|D3 `route.rechecked`|D4 같은 방문자가 안내표를 들고 옴|무료재확인 사건; 추가본업 안늘림|
|D4 `choice.lunch=defer/help`|D5 단비가 컵받침 얘기/점심메모 남김|관계대사1개, 포인트 차이0|
|D5 `week.firstComplete`|D6 게시판수료표 등장|고정 배경 decal, task보상중복 없음|
|D6 `conveyor.copied`|D7 결재함에 사본라벨|컨베이어 도감팁/화면 소품, 후속난도 강제 상승 없음|
|D7 `rules.conflictSeen`|D8 ‘감사규정은 잠겨 있습니다’ 공지|새규칙 요약, 실패라도 conflict근거도감 열림|
|D8 `macro.boundarySeen`|D9 재훈이100경계값 카드 남김|경계값도구 상점 해금은day8, 이후대사/무료샘플만|
|D9 `owner.returned`|D10 단비 책받침 라벨|인물일화, 서류주인 숨김 뒤힌트 공개|
|D10 `approval.rescheduled`|D11 ‘출장 전에 전달완료’ 소식|다음 일정의설명variant, 해는둘다존재|

플래그는 score가 아니라 `completed/assisted + 사용한 해법 특징 + 명시선택`으로 채운다. `eventLedger` onceKey는 보상원장과 별도. `deliveredCallbacks`로 소식 reload 중복을 막는다. D15 결과는repeat첫날에서 전달; 이후회차의D1기사와 충돌하면 recap카드로 접는다. 읽지 않은 소식은 도감 사건 탭에서 재열람. 반복 퍼즐은 스토리event의onceKey를 재발행하지 않는다.

## 대표 대사·퀘스트 샘플

**첫 출근** — 소라: “이 책상이 내 자리예요. 원본은 왼쪽, 수정본은 오른쪽. 커피는 어디든 됩니다.” 목표: `내 자리 탭 → 서류1건 → 제출 도장 → 구역으로 복귀`. NPC 말을 재생하지 않아도 같은 규칙카드를 읽을 수 있다.

**서식 변경** — 미루: “새 서식은 오늘부터래요. 공지는 어제 보냈다고 합니다.” 목표: 세 사례를 모두 허용/보완 기준대로 처리하는 가상 규정1칸 개정. 퀘스트: “잠긴 감사 조건을 지키며 게시판 공지를 고쳐주세요.”

**최종본 혼란** — 재훈: “최종, 진짜최종, 보낸최종. 승인된 건 가운데 하나예요.” 선택: `공용 링크 공유 / 내 메모에 기록`. 결과: 내일 같은파일을 물어보는 대신 메모에 작은 승인표시.

**점심시간 순삭** — 단비: “메뉴는 제육이었대요. 저는 회신을 먹었습니다.” 선택: `협조는 오후에 / 지금 간단히 회신`. 본업조건/포인트 동일, 다음날 한줄만 변화.

**결재 반려** — 서윤: “내용은 맞아요. 수요일은 제가 없는 날입니다.” 결과 안내: “회계→과장 순서는 맞습니다. 과장 가능시간은 목요일입니다.” 버튼: `일정 수정 / 힌트 / 보조 제출`. 실패낙인은 없음.

**타과 협조** — 하루: “저희가 먼저 보내면, 그쪽도 먼저 읽어주실까요?” 퀘스트: “청사 지도에서 자원순환과를 도와주세요. 오늘 퇴근 조건에는 포함되지 않습니다.” 팩미설치: “다음 버전 협조 신청만 받아둘게요.”

**마무리** — 과장: “잘 받았습니다.” (0.5초) “다음엔 새 서식입니다.” 주인공: “그럼 오늘 파일명에는 최종을 빼겠습니다.” 엔딩 소품 달력의 ‘금일중’ 글씨만 바뀐다. 의무적인 감동/훈계는 없음.

## 검수와 콘텐츠 제작 계약

모든 대화1화면3문장/선택2개, 클릭/탭으로 즉시 완료, 자동타이핑/성우 필수아님. 스토리 미루기/건너뛰기는 보상·해금에 동일한 기본효과를 실행하고 도감재열람 가능. `EventNarrative`는 조건없는 기본 variant를 반드시 갖는다. content삭제/번역누락 시 eventId 표시 대신 안전한 기본대사. 15일 각각 신규유형 등록/필수4건/선택서고/회신폴백/onceKey를 자동 검사한다. 대표콜백12개는 direct/assisted/skip 세 경로로 시뮬레이션한다.
