# 홍보물 200부: 예산판과 공문 작업대 디자인

붙임 네 개에서 읽은 방향은 짧은 목표, 크게 보이는 조작판, 사물 모양의 조작 대상, 가까이 표시되는 결과, 고정된 하단 버튼이다. 짙은 녹색 테두리와 크림색 판은 이 구성을 묶어준다. 이전 목업의 길게 이어지는 카드와 수첩을 줄이고, 돈과 종이를 다루는 작업판을 중심에 놓았다.

[직접 플레이](E01_묶음1_휴대용시안.html) · [이전 화면과 비교](E01_묶음1_디자인비교.html)

## 붙임에서 반영한 점

|참고 시안|화면에서 읽은 장점|이번 두 화면에 적용|
|---|---|---|
|거르기 블록|목표와 명령 조작이 같은 판 안에 있음|목표 200부를 제작 카드에 붙이고 칩 조작을 바로 옆에 배치|
|예산표 배정|주 작업판이 중심이며 오류가 해당 위치에 표시됨|공문에서 확인이 필요한 칸에 빨간 테두리와 메모 표시|
|그물 풀기|진행 수치가 적고, 조작 결과가 판에 바로 보임|총·배정·미배정 칩과 카드 선택 상태를 즉시 갱신|
|서가 빼내기|나무·종이·물체의 모양이 조작 방식을 설명함|칩 묶음, 종이 겹침, 나무 작업대, 붙임 클립, 담당 도장으로 표현|

첨부 시안의 게임 코드·격자·판정 로직은 사용하지 않았다. 이번 에피소드 전용으로 만든 예산·문서 상태 규칙을 사용하며, 이전 프로젝트의 퍼즐 모듈과 저장 자료에 접근하지 않는다.

## 1번: 예산 쟁탈전

시작 화면에서 26칩을 총 예산으로 보여준다. 제작 카드의 ‘20칩 놓기’를 한 번 누르면 10칩 묶음 두 개가 올라가고 미배정 칩이 6으로 바뀐다. 데스크톱에서는 같은 버튼을 카드에 끌어 놓을 수도 있다. 지원 카드는 카드 전체가 버튼이며, 선택하면 ‘배정됨’, 다시 누르면 회수된다.

견적을 확인하면 제작 단가가 1,000원에서 1,100원으로 오른다. 노란 연락 메모가 제작비 2칩 추가를 알려준다. 남긴 칩이 있으면 ‘2칩 옮기기’로 바로 반영한다. 칩이 부족하면 메모가 회수해야 한다는 이유를 알려주며, 지원 선택을 바꾼 뒤 같은 작업을 이어간다.

기본 제작비를 20번 누르는 과정과 별도 ‘작업 확인’ 버튼을 없앴다. 필수 제작비를 준비하고 지원 선택을 확정하면 공문 작업대로 넘어간다. 지원 선택은 현재 에피소드 규칙의 비용·후속 효과를 유지하며, 이 화면만으로 후속 재미를 검증한 것은 아니다.

## 2번: 공문 작업대

기안문의 수량·단가·운영시간은 44px 이상의 버튼이며, 숫자는 16px 이상으로 표시한다. 칸을 먼저 누르면 종이 아래에서 관련 자료 두 장이 펼쳐진다. 날짜와 내용을 비교해 자료를 누르면 그 값이 선택한 칸에 들어간다. 선택한 칸을 다시 누르면 자료함이 닫힌다.

견적 자료는 단가를 가져오는 경우와 붙임을 바꾸는 경우에 같은 자료를 사용한다. 붙임의 클립 두 칸에서는 교체한 장수를 보여준다. 가져온 값은 파란색 계열의 편집 상태, 선택 중인 칸은 노란색, 제출 후 확인이 필요한 칸은 빨간색과 문자 메모로 구별한다. 편집 상태를 정답 확인으로 표현하지 않는다.

‘기안 완료’ 한 번으로 검토와 완료를 처리한다. 문제가 있으면 해당 칸만 다시 확인하고 나머지 내용은 유지한다. 완료하면 담당 확인 도장이 찍힌 서류철이 나온다. 협조·계장·과장 결재는 다음 단계로 표시했다.

## 화면과 동작 확인

390×844에서는 예산판, 공문과 자료 선택창이 각각 작업판 안에 들어가며 하단 실행 버튼도 보인다. 320×740에서는 내부 작업판만 스크롤하고 하단 버튼은 고정된다. 430·768·1440px 너비에서도 페이지 가로 넘침과 실행 버튼 잘림을 확인했다.

브라우저에서 편성, 단가 상승, 칩 부족과 회수, 자료 오선택과 수정, 되돌리기, 기안 완료까지 확인했다. 검사 기록은 `E01_pair_design_validation.json`에 저장했다. 실제 이용자에게 조작의 이해도와 재미를 평가받는 단계는 남아 있다.

이번 시안은 1·2번에 한정된다. 다음 여섯 장면의 디자인과 배포된 게임 반영은 포함하지 않는다.
