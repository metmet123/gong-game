01 / 제공한 기획과 시안
사무실 감성은 유지하고, 업무 카드를 중심에 둡니다.
시안의 크림색 종이, 녹색 메뉴, 작은 사무실 캐릭터는 게임의 개성을 만듭니다. 다만 첨부 HTML의 최종 방향은 자유 이동보다 업무 퍼즐 70% · 성장 20% · 사무실 연출 10%입니다. 아래 제안도 이 방향을 기준으로 구성했습니다.
사용자 제공 시안 1 · 화면 중심부를 보이도록 표시
사용자 제공 시안 2 · 화면 중심부를 보이도록 표시
짧고 다양한 업무
첨부 기획의 20초~2분 단위를 유지합니다. 비교·분류·기억·순서·판단이 번갈아 나오게 합니다.
성장은 조작 편의로
공격력 대신 핵심 메모, 대조 강조, 중복 제외처럼 일을 더 잘하게 되는 보조 기능을 해금합니다.
실수해도 하루는 진행
수정 요청과 재제출로 학습하게 합니다. 난이도가 스토리와 승진을 막지 않도록 합니다.
읽는 기준 ‘확인한 게임 방식’은 공식 제품 소개에서 확인한 내용입니다. ‘이미지에서 볼 부분’은 공개 이미지 관찰, ‘적용 제안’과 수치·개발 구조는 이 기획에 맞춘 설계 제안입니다. 상용 게임의 내부 소스 코드나 판정 알고리즘을 확인한 자료는 아닙니다.
02 / 상용 게임의 접근 방식
게임마다 ‘일하는 재미’를 만드는 방법이 다릅니다.
소재가 같은 게임뿐 아니라, 검토·대화·자동화·마감·손으로 완성하는 조작을 참고할 수 있는 게임을 골랐습니다. 이미지를 클릭하면 확대할 수 있습니다.
01
문서 검토 · 가장 직접적인 참고
Papers, Please
Lucas Pope / 3909 · 2013
공식 소개 ↗
서류를 읽는 행동이 그대로 게임이 된다.
문서 심사 화면: 여러 증빙을 책상 위에서 비교한다. 원본신문 화면: 업무 바깥의 사건과 하루의 맥락을 전달한다. 원본
확인한 게임 방식
국경 심사관이 여행자의 문서와 검사·수색·지문 시스템을 이용해 입국 허용, 거부 또는 체포를 결정한다. 제공된 자료를 근거로 판단하는 구조가 핵심이다.
이미지에서 볼 부분
심사 공간, 방문자, 책상 위 여러 문서를 한 화면에 배치한다. 문서를 겹쳐 놓는 형태여서 “자료를 받아 검토한다”는 업무 감각이 강하다. 다른 이미지의 신문은 사건의 맥락을 전달한다.
공무원 키우기 적용 제안
예산 원본과 제출안을 나란히 놓고, 틀린 항목을 터치한 뒤 “수정 요청”을 누르는 퍼즐로 전환한다. 한 문제에는 금액·기한·단위 중 1~3개만 다르게 설정한다.
범위 조절
책상 위에 문서를 많이 겹치면 모바일에서 읽기 어렵다. 작은 화면에서는 문서 2장과 현재 검토 항목만 보여주고, 확대·교차 강조를 제공한다.
내용 근거: 개발사·배급사가 제공한 Steam 공식 제품 소개 · 이미지: 같은 제품 페이지의 공개 이미지. 화면 배치에 대한 해석은 이미지 관찰에 기반한다.
02
대화 · 조건 판단 · 도구 성장
Lil’ Guardsman
Hilltop Studios · 2024
공식 소개 ↗
질문과 도구로 정보를 모으고, 마지막에 판단한다.
성문 심사 장면: 고정된 업무 공간과 도구 아이콘. 원본대화 장면: 방문자 정보와 반응을 보며 판단한다. 원본
확인한 게임 방식
성문을 맡은 Lil이 100명 이상의 등장인물에게 질문하고 도구를 사용해 통과 여부를 판단한다. 획득한 골드로 도구를 강화하며, 선택은 도시와 인물의 운명에 영향을 준다. 시간을 되돌려 더 높은 점수에 도전하는 장치도 있다.
이미지에서 볼 부분
방문자와 주인공, 도구 아이콘, 대사를 같은 장면에 둔다. 심사 업무를 캐릭터 대화와 익살스러운 상황으로 풀어낸다.
공무원 키우기 적용 제안
민원인의 요구 확인 → 추가 질문 1개 선택 → 가상의 부서 안내 규칙 확인 → 담당부서 연결로 구성한다. 성장 도구는 “핵심 메모 유지”나 “관계없는 부서 1개 제외”처럼 정보 해석을 돕게 한다.
범위 조절
모든 민원에 긴 대화를 넣으면 짧은 세션이 무너진다. 보통 업무는 3문장 내외, 이야기 사건만 대화를 확장한다. 실수 시 해당 대화에서 재시도할 수 있게 한다.

03
하루 결산 · 선택의 결과 · 책상 꾸미기
Death and Taxes
Placeholder Gameworks · 2020
공식 소개 ↗
단순한 판정에 다음 날의 결과를 붙인다.
업무 화면: 서류와 판정 도구가 놓인 책상. 원본외형 변경 화면: 업무 외 수집·꾸미기 요소. 원본
확인한 게임 방식
사무직 저승사자가 사람들의 생사를 결정하는 짧은 2D 서사 게임이다. 선택은 주변 세계에 영향을 주며 여러 결말로 이어진다. 상사와의 대화, 수입, 상점, 책상 장식과 업그레이드 요소를 포함한다.
이미지에서 볼 부분
책상 위 인물 서류와 판정 도구가 주 화면이다. 작업 공간을 고정해 시선을 서류에 집중시킨다. 다른 이미지에서는 캐릭터 외형 변경 화면을 볼 수 있다.
공무원 키우기 적용 제안
업무 판단 → 결과 메모 → 다음 날 동료의 한마디로 연결한다. 누락 자료를 찾아주면 다음 날 정확한 자료가 도착하는 식으로, 플레이어의 선택이 사무실 분위기에 남게 한다.
범위 조절
생사 판단이라는 원작 소재보다 “짧은 판정 + 후속 반응” 구조를 참고한다. 정답이 있는 업무 퍼즐과 취향에 따른 이야기 선택은 구분해 표시한다.

04
반복 업무 자동화 · 순서 퍼즐
Human Resource Machine
Tomorrow Corporation · 2015
공식 소개 ↗
명령을 배열하면 사무원이 실제로 실행한다.
업무 퍼즐: 입력·출력과 오른쪽 명령 목록. 원본더 복잡한 명령 배열: 실행 흐름을 화면에 드러낸다. 원본
확인한 게임 방식
상사가 제시한 업무를 작은 사무원에게 프로그램으로 수행하게 하는 퍼즐이다. 성공하면 다음 층의 새로운 업무로 승진한다. 프로그래밍 경험이 없는 사람도 퍼즐로 접근하도록 설명하며, 숙련자를 위한 추가 도전도 제공한다.
이미지에서 볼 부분
왼쪽에는 입력과 출력, 중앙에는 작업 공간, 오른쪽에는 명령 목록이 있다. 명령과 작업 결과를 함께 볼 수 있어 실행 과정을 확인하기 쉽다.
공무원 키우기 적용 제안
자료 수집 → 중복 제거 → 합계 계산 → 제출의 블록을 배열한다. 실행하면 샘플 데이터가 단계별로 변하고, 오류가 난 단계에서 멈춘다. 통과한 자동화는 이후 쉬운 반복 업무를 줄여준다.
범위 조절
처음부터 점프·반복·분기 명령을 모두 열지 않는다. 선형 4블록 → 조건 1개 → 반복으로 확장한다. 단일 샘플만 맞추는 답을 막기 위해 여러 입력을 검증한다.

촉감 있는 조작 · 차분한 업무 연출
Assemble with Care
ustwo games · 2020
공식 소개 ↗
작은 작업을 손으로 완성하는 만족감을 준다.
시계 수리: 부품과 조립 대상을 크게 배치한다. 원본카메라 수리: 내부 부품을 분리해 보여준다. 원본
확인한 게임 방식
수리공 Maria가 물건의 내부 작동을 이해하고 수리하면서 마을 사람들과 연결되는 퍼즐 게임이다. 오래된 물건을 고치는 활동과 인물의 이야기를 함께 구성한다.
이미지에서 볼 부분
시계나 카메라의 부품을 작업대에 펼쳐 놓고 대상을 크게 보여준다. 부품의 형태와 위치가 조작의 단서가 된다. 부드러운 색감이 작업 공간의 분위기를 만든다.
공무원 키우기 적용 제안
공문 조각을 순서대로 끼우고, 스테이플러로 묶고, 결재 도장을 찍는 짧은 마무리 연출을 넣는다. 정답을 낸 뒤 1~2초의 완료 반응으로 “업무 하나를 끝냈다”는 감각을 준다.
범위 조절
원작의 입체 물체 수리를 그대로 제작할 필요는 없다. 현재 기획에는 2D 카드·도장·종이 소리로 조작감을 구현하는 편이 범위에 맞는다.

Overcooked
Ghost Town Games · 2016
공식 소개 ↗
쉬운 작업도 동시에 쌓이면 판단이 필요해진다.
주방 작업 장면: 작업대 배치와 동선이 협조를 만든다. 원본캐릭터 연출: 작업을 수행하는 공간과 인물을 보여준다. 원본
확인한 게임 방식
1~4명이 주문에 맞춰 준비·조리·서빙하는 요리 게임이다. 다양한 주방 환경에서 협력과 조율이 중요하며, 간단한 조작을 바탕으로 작업과 공간의 복잡성을 높인다.
이미지에서 볼 부분
작업대, 조리대, 인물의 위치가 한눈에 보이는 주방이다. 장애물과 배치가 협조 방식에 영향을 준다. 첨부 이미지에는 작업 장면과 캐릭터 연출이 보인다.
공무원 키우기 적용 제안
오늘의 업무 카드에 마감·예상 시간·협조 대기 여부를 표시한다. 자료 회신을 기다리는 동안 짧은 검토 업무를 먼저 처리하는 선택을 만든다.
범위 조절
직접 이동과 실시간 멀티플레이를 도입하면 현재 기획의 범위가 크게 바뀐다. 참고할 부분은 업무 대기열과 우선순위이며, 강한 시간 압박은 선택 도전 모드에 둔다.

05 / 개발할 때의 구성
화면은 재사용하고, 문제·규칙·보상을 데이터로 분리합니다.
아래는 이 프로젝트를 위한 구현 설계입니다. 비교 대상 게임이 실제로 이 구조를 사용한다는 의미는 아닙니다.
① 공통 진행 관리자
하루 시작 → 카드 선택 → 문제 → 판정 → 결과 → 성장 → 결산을 명시적인 상태로 관리합니다. 결과 버튼을 여러 번 눌러도 보상이 중복 지급되지 않도록 완료된 업무 ID를 기록합니다.
② 퍼즐별 화면과 판정기
비교·분류·기억·순서·판단의 화면을 5개 만듭니다. 화면은 선택 정보를 내보내고, 판정기는 정답과 피드백을 반환합니다. 업무 이름이나 문서 숫자에 판정 로직을 고정하지 않습니다.
③ 문제 템플릿과 생성 규칙
원본을 먼저 만들고 지정한 필드만 바꿔 제출안을 생성합니다. 합계·항목 값의 관계를 확인하고, 의도하지 않은 추가 오류가 생기면 출제를 취소합니다. 무작위 숫자만 바꾸는 방식은 피합니다.
④ 도구와 성장 데이터
경험치는 숙련 계열별로 저장합니다. 도구는 시간 증가, 메모 1개 유지, 교차 강조, 쉬운 업무 자동 처리로 구분합니다. 자동 처리는 기본 퍼즐을 이미 통과한 업무에 적용합니다.
