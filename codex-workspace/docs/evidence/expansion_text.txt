03 / PROGRESSION
하루는 단순하게, 업무는 새롭게
출근 · 오늘 4건→사무실 물건 선택→확대 퍼즐→제출 · 성장→문으로 퇴근
첫 5일: 현재의 1차 게임 5종으로 기본 조작을 익힌다. 기존 플레이 기록과 수료 흐름을 유지한다.
둘째 주: 하루 4건 중 기본 업무 2건 + 익숙한 확장 1건 + 새 퍼즐 또는 재도전 1건으로 편성한다. 새 조작은 하루 최대 1종이다.
선택 휴식: 서고 상자 밀기는 퇴근 조건에 포함하지 않는다. 하루 1회 완료 시 집중력 +10만 제안하며 경험치·업무 포인트를 반복 지급하지 않는다.
세 번째 주: 예산과 보고서 퍼즐을 도입한다. 긴 퍼즐 두 개를 같은 날 필수로 넣지 않고, 전체 하루 플레이 5–10분을 목표로 레벨 수치를 조정한다.
제안 시점처음 여는 퍼즐전제 경험소개 방식
6일차결재 컨베이어서류 검토 2건계장님의 짧은 시범 + 장치 2개
7일차규정 개정담당부서 안내 2건게시판의 새 공지
8일차매크로 디버깅업무 자동화 2건PC에서 첫 실행 오류 찾기
9일차서류 주인 찾기전화 메모 2건복사기에 남은 한 장
10일차결재 동선컨베이어·규정 각 1건회의 테이블에서 이번 주 결재 확인
6일차 이후 선택서고 정리그날 메인 업무 2건캐비닛 앞 잠깐의 정리
3주차 이후예산·한 장 보고각 선행 퍼즐 완료한 날에 한 종류씩 소개
A 단계만 구현됐을 때는 9일차 이후에도 A 단계와 기존 퍼즐을 반복 편성합니다. 아직 없는 퍼즐을 오늘의 필수 업무로 넣지 않습니다. 선행 경험이 부족하면 연습 업무로 대체하며 퇴근을 막지 않습니다.
보상과 실수
메인 완료는 현재처럼 경험치 +15, 포인트 +20, 집중력 −8. 퇴근 +15 P. 잘못 제출하면 10점 감점하되 최소 60점, 정답 확인 후 완료는 60점. 편집·되돌리기·미리보기는 감점하지 않는다.
완료가 막히지 않게
쉬움·보통·어려움은 조건 수를 바꾼다. 퍼즐이 길어지면 힌트나 정답 확인으로 그날의 업무를 끝낼 수 있다. 반복 입력과 오래 기다리는 캐릭터 이동으로 플레이 시간을 늘리지 않는다.
04 / PUZZLE SPECIFICATION
퍼즐 8종의 구체적인 구현안
첨부의 큰 제목과 확인 가능한 설명을 바탕으로 구체화한 제안입니다. 작은 글자의 수치를 그대로 전사한 사양은 아닙니다. A부터 구현하고 B·C는 순차 확장합니다.
전체 8종A · 업무 시스템 3종B · 사무실 확장 3종C · 고급 업무 2종
01
단계 A
결재 컨베이어 — 도장 공장 짓기
90초–3분
결재 서류가 검사·분류·도장·출력 장치를 거쳐 목표 결재함에 도착하도록 작은 처리 라인을 만든다.
시작 장소
내 자리 PC → 계장님 결재
해금 제안
6일차 · 기존 서류 검토 2건 완료
화면과 조작
중앙 6×5 작업 격자, 왼쪽 장치함, 오른쪽 입력 서류와 목표 결재함. 실제 사무실은 배경으로 남고 확대 작업대에서 조립한다.
장치를 선택한 뒤 빈 칸을 눌러 설치한다. 회전 버튼으로 방향을 바꾸고, 지우기·되돌리기로 수정한다.
실행하면 서류가 한 칸씩 이동하고 검사 결과에 따라 갈라진다. 일시정지와 한 단계 실행을 제공한다.
초급은 직선 이송+도장, 중급은 승인 여부 분기, 고급은 서로 다른 두 출력함을 사용한다.
판정과 실제 예시
입력 3건부터 시작한다. 승인 서류는 결재함, 미승인 서류는 보완함에 도착해야 한다.
모든 입력이 정확한 곳에 도착하고 잘못 찍힌 도장이 없어야 통과한다. 장치 수 제한은 고급 선택 목표로 둔다.
벽 밖 이동, 끊긴 연결, 순환 경로를 실행 전에 표시한다. 틀린 설계는 편집 상태를 유지한다.
예시 레벨
승인 A·미승인 B·승인 C → 검사기 → 승인만 도장기 → A·C는 결재함, B는 보완함. 경로 모양이 달라도 결과가 맞으면 인정한다.
연출·힌트·검수 기준
연출
장치가 덜컥 움직이고, 서류가 레일을 따라 이동한다. 잘못 연결된 칸은 흔들림과 “여기서 멈췄어요” 표시로 알려준다.
힌트 3단계
막힌 연결 한 곳을 가리키기 → 한 입력의 이동 경로 보기 → 유효한 예시 설계 보기.
검수
순환·빈 칸·격자 밖 이동 탐지, 분기 양쪽 결과, 모든 서류의 도착 수, 서로 다른 정답 설계 인정. 자동 실행은 최대 단계 수를 둔다.
02
단계 A
규정 개정 — 문장을 바꿔 민원 해결
60초–2분
규정 문장의 조건 카드를 바꾼 뒤 여러 민원 사례에 적용해, 요청한 처리 결과가 나오도록 규칙을 고친다.
시작 장소
게시판 → 민원 창구
해금 제안
7일차 · 담당부서 안내 2건 완료
화면과 조작
위쪽은 변경할 가상 규정, 가운데는 교체할 단어·조건 카드, 아래쪽은 사례 3건과 기대 처리 결과.
변경 가능한 조건 칸을 누르고 카드 목록에서 교체한다.
“사례에 적용”을 누르면 한 사례씩 허용·보완·반려 결과가 나온다.
초급은 단어 1개, 중급은 조건 2개, 고급은 조건 우선순위까지 수정한다.
판정과 실제 예시
무엇을 바꿀 수 있는지와 각 사례의 목표 결과를 미리 제시한다. 한 사례를 해결하고 다른 사례를 망가뜨리면 통과하지 못한다.
모든 제공 사례의 결과가 목표와 맞아야 완료한다. 동등한 규칙 문장은 모두 인정한다.
실제 법령 대신 게임 안에서 정의한 가상 규정을 사용한다. 애매한 표현은 정답 조건에 사용하지 않는다.
예시 레벨
“사전 신청자만 이용 가능”을 “사전 신청자 또는 현장 접수자 이용 가능”으로 수정. 사전 신청·현장 접수는 허용, 미접수는 보완 요청으로 분류한다.
연출·힌트·검수 기준
연출
카드를 바꾸면 게시판 문장이 붙였다 떼는 종이처럼 교체된다. 사례마다 허용·보완 표시가 하나씩 켜진다.
힌트 3단계
실패한 사례만 표시 → 적용된 조건 표시 → 필요한 조건의 종류 제시.
검수
허용된 카드만 편집 가능, 모든 사례 재평가, 조건 우선순위 충돌 검출, 여러 유효 문장 인정, 정답 없는 문제 생성 금지.
03
단계 A
매크로 설계 & 디버깅
90초–3분
현재의 명령 순서 퍼즐을 확장해, 반복 업무를 처리하는 프로그램을 만들고 실패한 줄을 찾아 수정한다.
시작 장소
내 자리 PC
해금 제안
8일차 · 기존 업무 자동화 2건 완료
화면과 조작
왼쪽 입력표, 중앙 처리 블록, 오른쪽 단계별 실행 로그와 예상 출력. 좁은 화면에서는 입력·명령·로그 탭으로 전환한다.
초기 버전은 기존 위·아래 버튼 조작을 유지하고, 블록 추가·삭제 버튼을 덧붙인다.
“한 단계”로 데이터가 어떻게 바뀌는지 살피고 “전체 실행”으로 테스트 사례를 검증한다.
초급은 순서 수정, 중급은 승인 필터·중복 제거, 고급은 조건 분기 또는 오류 블록 교체를 추가한다.
판정과 실제 예시
명령의 입력·출력 규약을 명확히 한다. 미수집 자료를 합산하거나 제출 후 처리하면 해당 줄에서 중단한다.
제시된 테스트 2–3개를 모두 통과해야 완료한다. 필터와 중복 제거의 순서처럼 결과가 같으면 둘 다 인정한다.
첫 확장에서는 임의 코드 입력과 무한 반복을 넣지 않는다. 반복 기능은 정해진 횟수와 실행 상한이 있는 후속 단계로 둔다.
예시 레벨
A 100·B 250·A 100·미승인 C 500 → 수집 → 중복 제거 → 승인 필터 → 합계 → 제출 = 350. 다른 입력 X 70·Y 30에서도 100이 나와야 통과한다.
연출·힌트·검수 기준
연출
캐릭터가 타이핑하고 실행 중인 블록이 차례로 밝아진다. 실패 줄 옆에 데이터 상태와 이유를 보여준다.
힌트 3단계
실패한 줄 강조 → 실행 직전 데이터 보기 → 필요한 명령 종류 제시.
검수
현재 자동화 정답과 보조 도구 호환, 복수 정답 순서 인정, 각 테스트 격리 실행, 실행 로그 정확성, 실행 횟수 상한.
04
단계 B
서류 주인 찾기 — 추리
60초–2분
공용 설비에 남은 서류와 메모·일정·담당 업무를 대조해 서류를 받아야 할 동료를 찾는다.
시작 장소
복사기·프린터 → 동료 자리
해금 제안
9일차 · 전화 메모 2건 완료
화면과 조작
서류 한 장, 단서 카드 3–5개, 동료 후보 3–4명. 후보 선택 시 관련 단서가 나란히 표시된다.
서류의 날짜·문서 종류·담당 항목을 누르면 확대한다.
동료의 짧은 말풍선과 업무표를 열어 단서를 모은다.
동료를 선택하고 “서류 전달”을 누른다. 초급은 후보 3명, 고급은 일정 조건을 추가한다.
판정과 실제 예시
모든 필수 단서는 화면 안에서 얻을 수 있어야 한다. 직감이나 캐릭터 외모로 정답을 추측하게 만들지 않는다.
단서를 모두 만족하는 후보가 정확히 1명일 때만 문제를 채택한다.
별명을 서류 내용에 몰래 쓰는 함정은 피한다. 이름과 업무 정보는 필요할 때 다시 확인할 수 있다.
예시 레벨
정산 서류·오늘 마감·오후 회의 전에 제출이라는 단서. 회계 담당 세 명 중 정산 담당이면서 오늘 출근한 후보 한 명에게 전달한다.
연출·힌트·검수 기준
연출
단서를 확보하면 메모 핀이 붙고, 후보를 고르면 근거끼리 선으로 연결된다. 정답 전달 시 동료가 서류를 받는다.
힌트 3단계
중요한 단서 표시 → 모순되는 후보 한 명 제외 → 정답 근거 설명.
검수
정답 후보 1명 보장, 단서 누락 검사, 후보 순서 변경에도 판정 동일, 이름·표정 변경이 판정에 영향을 주지 않음.
05
단계 B
결재 동선 짜기 — 금요일까지 끝내라
2–4분
결재 순서와 담당자의 가능한 시간을 보고, 마감 전에 제출되는 업무 일정을 짠다.
시작 장소
회의 테이블 → 해당 업무의 담당 계장님 → 과장님
해금 제안
10일차 · 컨베이어 1건 및 규정 개정 1건 완료
화면과 조작
월–금 시간표, 문서의 선행 조건, 담당자 가능 시간. 확정 후 실제 사무실 배치 위에서 전달 경로를 재생한다.
업무 카드를 날짜·시간 슬롯에 배치한다. 모바일은 카드 선택 → 슬롯 선택으로 조작한다.
“미리 재생”을 누르면 어떤 서류가 어디에서 기다리는지 확인한다.
초급은 계장 1명+과장, 중급은 담당 계장 2명, 고급은 회의·부재 슬롯을 추가한다.
판정과 실제 예시
결재 순서와 소요 시간은 문제에 제시한다. 모든 계장님을 무조건 거치게 하지 않는다.
선행 업무 완료 뒤 다음 결재를 시작하고, 담당자 부재·동일 시간 중복 없이 금요일 마감 안에 제출하면 통과한다.
사무실을 걸어가는 연출 시간은 점수에서 제외한다. 일정 퍼즐과 캐릭터 이동 경로 계산은 별도로 처리한다.
예시 레벨
자료 보완 월 오전 → 담당 계장 월 오후 → 협조 계장 수 오전 → 과장 목 오후 → 제출 금 오전. 담당자가 목요일 부재면 다른 가능한 슬롯으로 조정한다.
연출·힌트·검수 기준
연출
달력 위 문서가 날짜별로 이동하고 마지막 제출함에 들어간다. 실패 시 “수요일 결재 전 보완 미완료”처럼 막힌 지점을 표시한다.
힌트 3단계
첫 충돌만 표시 → 담당자의 가능한 시간 강조 → 한 단계의 유효 슬롯 제시.
검수
순환 선행 조건 금지, 존재하는 해를 먼저 생성, 휴무·중복·마감 판정, 복수 유효 일정 인정, 실제 배치의 통로로만 이동.
06
단계 B
서고 정리 — 상자 밀기
30초–90초
좁은 보관 공간에서 연도가 표시된 상자를 해당 연도 칸에 밀어 넣는 짧은 공간 퍼즐.
시작 장소
캐비닛 3곳·책장 → 서고 작업 화면
해금 제안
6일차 이후 선택 휴식 · 메인 업무 2건 완료 시 하루 1회
화면과 조작
처음에는 5×5 작은 격자와 상자 1개. 안내는 “밀기만 가능” 한 줄, 아래에 방향 버튼·되돌리기·처음부터.
방향키·WASD 또는 화면 방향 버튼으로 이동한다.
상자 뒤에서 이동하면 상자를 한 칸 민다. 당기기는 없다.
초급 상자 1개, 중급 2개, 고급은 여러 연도 칸과 벽을 추가한다.
판정과 실제 예시
각 상자를 같은 연도의 목표 칸에 놓으면 완료한다. 이동 수는 선택 기록이며 시간 제한은 없다.
되돌리기는 무제한으로 제공한다. 모서리에 막힌 경우 재시작을 안내한다.
미니 서고 퍼즐의 벽과 사무실의 캐비닛 좌표는 서로 다른 데이터다. 사무실 가구를 직접 밀어 이동시키지 않는다.
예시 레벨
2025 상자를 2025 칸으로 밀어 넣는다. 상자 오른쪽을 비우고 반대편으로 돌아갈 공간을 남겨야 한다.
연출·힌트·검수 기준
연출
상자가 짧게 미끄러지고 종이 먼지가 튄다. 목표 칸에서는 연도 도장이 찍힌다.
힌트 3단계
다음 한 번의 유효 밀기 표시 → 목표 방향 보기 → 해결 경로 재생.
검수
풀이 가능한 고정 맵부터 사용, 밀기·충돌·되돌리기 완전 복원, 여러 상자 목표 매칭, 선택 휴식 없이도 정상 퇴근 가능.
07
단계 C
예산 테트리스
2–4분
사업별 기간과 월별 비용을 블록으로 표현하고, 연간 예산 격자에 조건을 지키며 배치하는 턴 방식 퍼즐.
시작 장소
내 자리 PC → 회의 테이블
해금 제안
3주차 이후 · 매크로 2건 완료
화면과 조작
12개월×예산 4칸 격자, 사업 블록 3개, 분기별 한도 표시. 모바일은 가로 6개월씩 두 페이지로 나누되 사업 배치 결과는 하나로 유지한다.
사업을 고르고 시작 월을 누른다. 놓기 전 미리보기로 기간과 비용을 확인한다.
배치한 사업은 이동·회수할 수 있다. 빠르게 떨어지는 블록은 사용하지 않는다.
초급은 같은 크기의 사업, 중급은 기간·금액 차이, 고급은 분기 한도와 실행 가능한 기간을 추가한다.
판정과 실제 예시
가로는 기간, 세로는 월별 금액이므로 블록을 회전하지 않는다. 회전하면 기간과 비용 의미가 바뀐다.
사업을 모두 배치하고 월별·분기별 한도를 넘지 않으며 최소 연속 기간을 지키면 완료한다.
금액은 게임용 예산 단위로 단순화한다. 일반 테트리스처럼 줄을 지워 사업 기록을 없애지 않는다.
예시 레벨
교육 3개월×1칸, 시설 2개월×2칸, 상담 4개월×1칸을 지정 가능 기간 안에 배치. 한 달 합계 4칸, 분기 합계 8단위를 넘지 않도록 조정한다.
연출·힌트·검수 기준
연출
사업별 색과 기호로 블록을 구분한다. 한도 초과 월·분기만 경고하고 해당 사업은 되돌릴 수 있게 남긴다.
힌트 3단계
초과한 기간 강조 → 여유가 있는 기간 표시 → 한 사업의 가능한 시작 월 제시.
검수
시간·금액 축 변경 금지, 월·분기 합계 일치, 페이지 사이에 걸친 사업 표시, 불가능한 기간 배치 금지, 복수 정답 인정.
08
단계 C
한 장으로 줄여 와
90초–3분
긴 보고서에서 필요한 내용을 선택하고 문장을 합쳐, 필수 키워드를 유지하며 정해진 보고서 분량 안에 넣는다.
시작 장소
내 자리 서류 → 과장님 보고
해금 제안
3주차 이후 · 서류 주인 찾기 1건 완료
화면과 조작
왼쪽은 원문 카드, 오른쪽은 한 장 보고서. 카드마다 비용 칸 수와 필수·선택 정보를 표시하고 남은 칸을 크게 보여준다.
문장 카드를 선택해 보고서에 넣거나 뺀다. 서로 관련된 두 카드는 제시된 요약 카드로 합칠 수 있다.
필수 키워드 체크와 분량 게이지를 보고 조정한다. 모바일은 원문·보고서 탭을 전환한다.
초급은 필수 정보 3개, 중급은 중복 문장 제거, 고급은 논리 순서와 보고 대상의 관심 조건을 추가한다.
판정과 실제 예시
필수 사실이 모두 남고 제한 칸 수 안에 들어가며 문장 순서 조건을 만족하면 완료한다.
정해 둔 카드와 요약 조합으로 판정한다. 초기에는 자유 문장 입력이나 AI 채점이 필요하지 않다.
폰트 크기나 실제 화면 줄 수 대신 카드별 고정 비용으로 분량을 계산해 모바일과 PC 결과를 같게 한다.
예시 레벨
“사업 목표” 2칸·“기간” 1칸·“예산” 1칸·중복 설명 3칸에서 필수 3항목을 4칸 안에 담는다. 의미를 유지한 요약 조합은 모두 인정한다.
연출·힌트·검수 기준
연출
빼도 되는 문장을 남기면 팀장 표정이 바뀌지만, 구체적 이유도 함께 표시한다. 완성 보고서에는 결재 도장이 찍힌다.
힌트 3단계
빠진 필수 사실 표시 → 중복 정보 카드 강조 → 사용할 수 있는 요약 조합 제시.
검수
필수 키워드 보존, 고정 비용 합계, 합치기·되돌리기 복원, 서로 다른 유효 요약 인정, 글꼴·화면 폭에 따른 점수 변동 없음.
05 / PRESENTATION
같은 배치, 더 살아 있는 사무실
사무실 화면
타일 기준 24px → 논리 공간 336×504. 물품 footprint는 14×21 JSON을 그대로 사용한다.
내 자리 PC·전화·서류는 2×2 책상 안의 소품으로 배치한다. JSON에 별도 가구 좌표를 추가하지 않는다.
처음에는 전체 배치, 업무 시작 때는 해당 물건을 살짝 확대한다. 모바일에서 가구 순서를 바꾸는 재배치는 하지 않는다.
동시에 보이는 업무 표시는 4건 중심. 모든 주무관 위에 버튼·이름을 항상 띄우지 않는다.
정보는 일차·남은 업무·포인트·집중력만 유지한다. 자세한 규칙은 해당 퍼즐에서 표시한다.
캐릭터와 이동
걷기 4프레임×4방향, 대기 2프레임. 전화·타이핑·서류 확인·도장·건네기·축하 동작을 순차 제작한다.
주무관 전체가 동시에 바쁘게 움직이지 않도록 작업·대기·짧은 대화의 타이밍을 분산한다.
각 물품에 접근 가능한 통로 칸을 지정하고 BFS/A*로 경로를 구한다. 도달할 수 없는 지점은 메뉴에서 안내한다.
책상 착석·소품 동작은 footprint 안의 지정 좌표에서 재생한다. 걷는 중 책상이나 칸막이를 관통하지 않는다.
긴 전달 이동은 속도를 높이거나 건너뛸 수 있게 한다. 애니메이션 끄기 시 즉시 접근·결과 표시가 가능해야 한다.
퍼즐주요 시각 요소완료 연출
컨베이어종이 레일·분기 장치·두 종류 결재함종이 3장이 정확한 함에 들어감
규정게시판 종이·교체 카드·사례 처리등정리된 공지가 고정됨
매크로PC 실행 블록·데이터 표·줄별 로그로그 전부 통과 + 캐릭터 타이핑 멈춤
추리서류·메모 핀·후보 프로필정답 동료가 종이를 받음
결재 일정주간 일정·담당자 슬롯·사무실 경로주간 일정 재생 후 금요일 제출 도장
서고연도 상자·벽·목표 칸상자에 연도 확인 도장
예산월별 격자·사업 모양·분기 한도예산 막대가 정리되고 승인 표시
보고문장 조각·한 장 양식·분량 게이지보고서 출력 + 과장님 확인
좁은 화면 규칙: 320·390px에서 문서 좌우 대조는 같은 항목 높이를 맞추고, 큰 작업 격자는 확대·이동 가능한 영역에 담는다. 퍼즐의 좌표와 규칙은 화면 폭에 따라 바뀌지 않는다. 터치 영역은 최소 44px를 목표로 하되 겹치면 물건 선택 창으로 전환한다. 제출·되돌리기는 화면 아래에서 항상 찾을 수 있게 한다.

이 문서는 구현 계획입니다. 현재 플레이 HTML과 실제 저장 데이터는 이 문서를 만들면서 변경하지 않습니다.
07 / DEVELOPMENT ORDER
다음 개발은 A 단계부터
날짜를 먼저 확정하지 않고, 각 단계의 완료 조건을 통과한 빌드를 기준으로 범위를 늘립니다. 자동화와 퍼즐 검수의 난도가 달라 단순히 8종을 한 번에 추가하지 않습니다.
M0 · 배치와 이동 기반 / 선행 작업
정확한 생활보장과 사무실 만들기
46개 물품을 JSON에서 그리기 → 착석 방향 반영 → 클릭 영역·통로·접근 칸 검수 → 기존 5종 퍼즐을 새 장소에 연결 → 기존 저장 유지 확인.
완료 기준: 모든 가구가 원본 좌표에 있고, 필요한 업무 장소에 접근 가능하며, 현재 하루 4건과 퇴근이 모두 동작한다.
M1 · A 단계 / 다음 플레이 빌드
컨베이어 + 규정 개정 + 매크로 디버깅
공통 편집·되돌리기·실행 로그부터 만들고, 기존 자동화 확장 → 컨베이어 → 규정 개정 순서로 구현. 난이도별 고정 레벨 3개, 각 최초 도입 연출 1개를 준비한다.
완료 기준: 최소 27개 고정 레벨을 검수하고 6–8일차 도입 흐름 및 이후 반복 출제를 확인한다. 모바일에서 드래그 없이 조립·수정·제출할 수 있다.
M2 · B 단계 / 사무실과 NPC 활용
주인 찾기 + 결재 일정 + 선택 서고
후보·단서 데이터 → 주간 일정 판정 → 실제 사무실 전달 연출 → 검수한 상자 맵. 동료가 많아져도 필수 후보만 표시하고 긴 이동은 생략 가능하게 한다.
완료 기준: 추리 정답 1명 보장, 일정의 유효 해와 경로 확인, 서고를 건너뛰어도 퇴근 가능. 9–10일차 도입에서 새 조작이 과하게 겹치지 않는다.
M3 · C 단계 / 고급 공간·요약 퍼즐
예산 테트리스 + 한 장 보고
의미가 바뀌지 않는 기간·금액 블록 → 월·분기 한도 → 고정 비용 보고서 카드 → 유효 요약 조합. 3주차 콘텐츠로 편성하고 전체 난이도를 다시 조정한다.
완료 기준: 모바일과 PC 판정 동일, 모든 제공 레벨 해결 가능, 색 없이 기호만으로도 사업·문장 구분 가능.
M4 · 전체 마감 / 저장·아트·사용성
처음부터 3주차까지 이어 플레이
단계별 저장 변환·오류 복구·보상 중복 방지 → 320px와 390px 실제 플레이 → 키보드·동작 줄이기 → 스프라이트와 소리 정리 → 단일 HTML 최종 번들.
완료 기준: 각 퍼즐 정상 완료와 정답 확인, 중도 닫기·새로고침, 퇴근과 다음 날, 기존 저장 가져오기를 실제 UI로 점검한다.
추천하는 바로 다음 범위는 M0 + M1입니다. 배치를 확정하고 새 업무 시스템 3종을 먼저 플레이 가능한 형태로 만든 뒤, NPC·주간 일정과 고급 예산·보고서 퍼즐을 추가합니다.
08 / ACCEPTANCE CRITERIA
완료 여부는 이렇게 확인합니다.
게임 규칙
검수용 모든 레벨에 유효 해가 있다.
한 문제에 여러 정답이 가능하면 전부 인정한다.
부분 답변·잘못된 답·정답 확인 후 완료가 구분된다.
보상·퇴근 보너스·선택 휴식은 중복 지급되지 않는다.
잘못 제출해도 편집과 재시도를 할 수 있다.
미구현 퍼즐·조건 미달 퍼즐이 필수 업무로 나오지 않는다.
배치·모바일·저장
46개 item의 좌표·크기·방향이 원본과 같다.
필수 업무 물품에 갈 수 있는 통로가 있다.
320×640, 390×844, 1280×800에서 주요 동작을 점검한다.
퍼즐 외 페이지에 가로 넘침이 없고, 제출 버튼을 찾을 수 있다.
모션 끄기·소리 끄기·키보드 조작이 동작한다.
기존 v1 저장과 확장 v2 저장을 각각 검수한다.
읽기·규정·일정 문제에는 강제 실시간 제한을 기본으로 두지 않습니다. 성취 기록은 남기되 실패 원인은 텍스트로 설명합니다. 색만으로 정답·오류를 구분하지 않고, 모든 버튼에 조작 가능한 이름을 붙입니다.
