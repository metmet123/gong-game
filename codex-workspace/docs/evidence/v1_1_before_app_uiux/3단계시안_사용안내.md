# 3단계 시안집 사용 안내

`공무원키우기_3단계시안_퍼즐우선계획.html`은 인터넷 연결 없이 열 수 있는 단일 HTML이다. 목차·129개 그림·본문은 JavaScript 없이도 보인다. 상단 검색은 JavaScript가 필요하다. 삼성/다른 앱의 첨부 미리보기는 환경에 따라 SVG·CSS를 제한할 수 있어 실제 기기에서의 표시와 조작은 미검증이다.

- PC: 왼쪽 목차에서 게임·장소·화면을 고른다. 세 단계가 나란히 보인다.
- 휴대폰: ‘게임·장소·화면 바로 찾기’를 펼쳐 항목을 고른다. 01→02→03 순으로 읽는다.
- 상단 ‘구현 순서’: PF0~PF6의 새 계획과 TASK39개로 이동한다.
- ‘대표 문제와 한 가지 유효 해법 보기’: 예제 조건·풀이·관련 TASK를 펼친다.
- TASK ID 링크: 해당 완료 기준과 직접 선행 목록을 확인한다. JavaScript가 차단되어 자동 펼치기가 없으면 제목을 눌러 펼친다.
- 검색: ‘결재 컨베이어’, ‘창구’, ‘PF1-BUD’처럼 입력한다. 검색어를 지우면 전체 그림이 다시 보인다.

시안 속 게임 실행·제출·구매 버튼은 화면 구성을 보여주는 그림이다. 아직 신규 게임 판정기를 구현한 것은 아니다. 같은 문제 조건을 세 완성도 단계로 보여주며, 난도 하/중/상과 구분한다. 03단계는 최종 자산 제작의 목표이며 최종 아트 확정안이 아니다.

이전 `공무원키우기_통합계획_탐색형.html`은 v1.0 스냅샷이다. 앞으로의 구현 순서는 새 시안집의 계획과 `docs/PUZZLE_FIRST_V1_1.md`, `docs/tasks_puzzle_first_v1_1.json`을 따른다. 원본 게임과 기존 규칙·배치·경제 데이터는 유지한다.

구현 요청을 전달할 때는 PUZZLE_FIRST_V1_1.md 마지막 착수 프롬프트를 사용한다. 지금 PF TASK는 모두 planned다. 첫 목표는 신규8종 각1문제를 독립 연습실에서 직접 편집·검증·제출·재시도하는 것이다. 다음은 하/중/상24문제+기존5종·초안/힌트, 그 후 사무실과 보상/스토리를 연결한다.
