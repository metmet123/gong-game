공통 판정과 인수 조건

  1. 판정은 DOM·캔버스·지도·벽시계·저장·XP/P에서 독립한 순수 함수다. Stage의 seed·난도·contentVersion은 시작 시 고정한다.
  2. 편집 action을 undo/reset으로 복원한다. 검증에서 초안을 지우지 않으며 미완료·위반·엔진오류를 구분한다.
  3. 복수해는 결과와 제약으로 판정한다. owner 기본은 유일해를 별도로 증명한다. 픽셀 위치·카드 이름·폰트·다른 행·정렬이 답을 바꾸지 않는다.
  4. PF1 최소문제도 실제 편집과 성공/실패가 있어야 한다. 정답 버튼·고정 witness 재생만으로 플레이 완료라고 하지 않는다.
  5. PF2부터 무료힌트3·보조완료·중도 초안을 제공한다. 실제 XP15/P20·일차결산15P는 PF4에서 원장과 연결한다.
  6. 휴대폰은 drag 없이 선택→칸탭/위아래로 풀 수 있어야 한다. 긴 격자는 내부 확대/이동·날짜/분기 탭으로 처리하고 하단 핵심 조작을 유지한다.
  7. PF4 경제 총수입1455P(시작30 포함), 도구690P+소품735P=1425P, 잔여30P를 재검사한다. 기존 도구 가격·해금일·난도별 보상은 변경하지 않는다.
  8. 신규 판정기 실행 시험, 24/72개 해존재 검사, 문서 그림 검증, 실제 Android 시험을 서로 다른 증거로 기록한다. 현재 3단계 HTML 검증은 신규 게임 완성 증거가 아니다.
