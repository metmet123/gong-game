# A 입문 · 독립 플레이 화면

`index.html`을 브라우저로 직접 열어 플레이할 수 있습니다. 외부 라이브러리·네트워크·기존 퍼즐 엔진을 사용하지 않습니다.

PC와 휴대폰에 같은 폴더를 제공하려면 프로젝트 루트에서 `python -m http.server 8897 --bind 0.0.0.0 --directory 생활보장과/src/leaflet-a`를 실행하고 PC는 `http://localhost:8897/`, 같은 Wi-Fi의 휴대폰은 `http://PC의내부IP:8897/`로 엽니다. 서버는 이 독립 화면 폴더만 제공합니다. 방화벽·네트워크 설정에 따라 휴대폰 접속이 제한될 수 있습니다. 파일 주소·localhost·다른 IP 주소의 저장은 별개입니다.

## 화면 방향

첨부된 기준 시안의 4장면을 독립 화면에 반영했습니다. 상단 단계 헤더, 좌측 업무 메모, 중앙 클립보드 공문, 우측 청록색 실물 시험대와 종이·메모·도장 표현을 사용합니다. 시안의 이미지 에셋을 그대로 복사하지 않고, 종이·안내대·지도·홍보물은 새 CSS/SVG로 구성했습니다.

## 플레이

1. 요청 메모의 세 조건을 확인하고 견본을 조사합니다.
2. 펼치기·뒤집기·지도 대조·안내대 비치로 실제 모습을 확인합니다.
3. 지도 대조와 안내대 장면에서 관찰을 남깁니다.
4. 제작할 견본을 공문에 선정하고 같은 견본의 기록 두 장을 붙입니다.
5. 공문에서 선정 검토를 요청합니다. 반려 시 해당 부분만 고칩니다.

조사 대상과 선정 대상은 별개입니다. 관찰 기록은 정답 판정이 아닙니다. 완료는 견본 선정 검토이며 전체 결재·발주·지출 완료가 아닙니다. 완료 결과를 JSON으로 내려받을 수 있습니다. 새 시도 시작 시 직전 완료본은 별도 로컬 키에 보관됩니다.

자동 저장: `gong-game:life-support:leaflet-a:v1`. 기존 게임 저장은 접근하지 않습니다. 소리 기본 꺼짐, 키보드 Tab·Enter·Space 조작과 Escape 확대 닫기, 동작 줄이기를 지원합니다.

## 코드와 자체 에셋

- model.js: 새 사건 데이터·조건 판정·관찰·복원·결과
- app.js: 새 사물 SVG/종이 표현·입력·공문·저장
- style.css: 새 독립 반응형 화면
- 지도·종이·안내대·QR 모양: 이 작업에서 직접 작성한 SVG/CSS. QR 모양은 스캔용이 아닙니다.
- 소리: 브라우저 oscillator의 짧은 합성음. 외부 이미지·글꼴·게임 에셋 없음.

중간·도전 및 B/C·본편 연결·공개 배포는 이번 입문 구현 범위에 포함하지 않습니다. 재미 검증은 사용자 체험 이후 별도로 기록합니다.
