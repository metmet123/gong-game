공무원 키우기

업무별 퍼즐을 풀고 숙련도와 자동화 능력을 키워, 더 능숙하게 하루를 마치는 공무원 성장 게임

2D 캐주얼 업무 퍼즐 두뇌게임 성장 시스템 가벼운 풍자 난이도 상·중·하

1. 최종 방향 요약

사무실을 직접 돌아다니는 시뮬레이션보다는, 실제 공무원 업무의 특징을 각각 다른 유형의 퍼즐로 바꾸는 방향을 기본으로 한다.

플레이어는 하루에 들어온 업무를 선택해 짧은 퍼즐을 해결하고, 그 결과에 따라 경험치·숙련도·업무 도구를 얻는다. 사무실과 동료들은 직접 이동하는 공간이 아니라, 업무 사이를 연결하는 배경·연출·이벤트 공간으로 활용한다.

70%업무 퍼즐
20%성장·수집
10%사무실 연출
3단계난이도 하·중·상

2. 게임의 핵심 컨셉

“업무를 처리하는 행위 자체가 퍼즐이 된다.”
현실 업무에서 가져오는 것
  • 예산·자료 검토
  • 자료 취합과 제출기한
  • 전화·민원 내용 기억
  • 정보공개 판단
  • 급식비·지출자료 대조
  • 공문·쪽지 구성
  • 담당자 협조와 결재
  • 반복 업무 자동화
게임용으로 바꾸는 원칙
  • 실제 업무 절차를 그대로 복제하지 않는다.
  • 20초~2분 내외의 짧은 퍼즐로 단순화한다.
  • 관찰·기억·분류·논리·순서 판단을 섞는다.
  • 실패해도 게임 진행이 막히지 않도록 한다.
  • 성장할수록 퍼즐을 더 편하게 풀 수 있게 한다.

3. 기본 플레이 루프

하루 시작→ 업무 카드 확인→ 업무 선택→ 퍼즐 진행→ 제출·결과→ 성장→ 하루 결산

한 번 플레이할 때 여러 업무가 카드 형태로 등장하고, 플레이어가 우선순위를 선택한다. 업무마다 다른 종류의 퍼즐이 등장하기 때문에 반복 플레이에서도 감각이 바뀌도록 구성한다.

4. 업무별 퍼즐 유형

업무퍼즐 유형게임 예시주요 능력
예산·사업설명서 검토틀린 부분 찾기원자료와 제출자료의 금액·연도·재원·단위 차이 찾기관찰·대조
자료 취합조건 분류요구 조건에 맞는 자료만 선택하고 중복·구버전 제외분류·판단
전화 민원기억력짧은 통화 후 이름·시간·요청사항·담당부서 기억단기 기억
정보공개논리 판단상황과 조건을 보고 공개·부분공개·부존재 등 선택논리·규칙 적용
급식비·지출자료대조 퍼즐명단·시간·지급액·입금내역 맞추기정확성
공문·쪽지 작성순서 배열배경·요청내용·기한·근거를 올바른 순서로 배치구조화
담당자 협조조건 추리누구에게 어떤 자료를 요청해야 가장 빠른지 판단업무 조율
결재최종 오류 탐색제출 직전 문서에서 숨은 오류·누락 찾기검토
반복 업무 자동화순서·블록 퍼즐자료 수집→정리→중복 제거→합계 계산→제출 순서 구성자동화 사고
돌발 민원·긴급 요청선택형 판단짧은 상황 설명을 보고 가장 적절한 대응 선택상황 판단

5. 퍼즐 스타일

순발력형빠른 판단

짧은 제한시간 안에 분류·선택·기억 문제를 처리한다.

예: 전화 내용 기억, 급한 자료 분류

추리형생각하는 판단

시간 압박을 줄이고 조건을 비교하며 답을 찾는다.

예: 정보공개 판단, 담당자 협조

혼합형기본 방식

순발력과 추리를 섞되, 강한 시간 압박은 일부 업무에만 사용한다.

게임의 기본 플레이 방식으로 사용한다.

6. 난이도 설정

설정에서 언제든 하 / 중 / 상을 선택할 수 있으며, 변경 내용은 다음 퍼즐부터 적용한다.

항목하중상
제한시간넉넉함기본짧음
조건 수1~2개2~3개3~4개 이상
힌트자동 강조 많음요청 시 제공제한적
실수 부담거의 없음재확인 시간 추가시간·점수 손실 증가
추천 대상가볍게 플레이기본 추천도전 플레이
난이도는 스토리·승진·아이템 해금에 불이익을 주지 않는다. 어려운 난이도는 점수·기록 경쟁용 보너스만 주는 방향이 적절하다.

7. 성장 시스템

성장은 단순 능력치 상승보다, 실제 플레이 방식이 편해지는 방향으로 설계한다.

성장 요소효과 예시
검토 숙련도오류 후보를 희미하게 표시하거나 비교 범위를 줄여준다.
업무 기억력전화 퍼즐에서 핵심 메모 한 줄을 유지할 수 있다.
자료 취합 숙련명백한 중복·구버전을 자동 제외한다.
업무 조율협조 요청 퍼즐에서 불필요한 선택지가 줄어든다.
자동화쉬운 반복 퍼즐 일부를 자동 완료하거나 단계 수를 줄인다.
노련함제한시간 증가, 실수 패널티 감소 등 전반적인 보조 효과.

8. 사무실 요소의 활용

사무실은 직접 탐색하는 메인 콘텐츠가 아니라, 퍼즐 사이의 분위기와 성장감을 보여주는 메타 화면으로 사용한다.
유지할 요소
  • 주인공 책상
  • 동료·팀장
  • 전화·프린터·PC
  • 서류 더미·결재함
  • 점심시간·퇴근 연출
연출 예시
  • 퍼즐 성공 후 주인공이 프린터로 이동
  • 동료가 “자료 보냈어요”라고 말함
  • 팀장에게 결재 올리는 짧은 애니메이션
  • 업무가 쌓이면 책상 위 서류 더미 증가
  • 퇴근 성공 시 PC를 끄고 사무실 불이 꺼짐

9. 화면 구성 초안

메인 화면
  • 상단: 날짜 / 직급 / 집중력 / 숙련도
  • 중앙: 오늘 들어온 업무 카드 3~5개
  • 하단: 업무 / 성장 / 도감 / 설정
  • 배경: 작은 사무실과 캐릭터 연출
업무 카드 예시

긴급2027년도 사업설명서 검토

난이도 ★★★☆☆

예상 소요시간 1분

보상: 검토 경험치 +15

10. 톤과 분위기

  • 현실 공감: 짧은 제출기한, 수정 요청, 서식 변경, 자료 취합 등 실제 업무에서 오는 상황을 소재로 사용
  • 가벼운 풍자: “금일 중 제출”, “최종_진짜최종”, “총액만 있으면 됩니다” 같은 상황을 유머로 활용
  • 교훈적이지 않게: 매번 감동적인 결말보다 짧고 건조한 웃음으로 마무리
  • 대상 비하 금지: 복지대상자나 민원인 자체보다 불합리한 절차·서식·업무환경을 풍자의 중심으로 삼음
  • 그래픽: 간단한 2D, 복고풍 또는 캐주얼 일러스트 스타일. 정교한 3D는 사용하지 않음
