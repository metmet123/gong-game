블록 배치 묶음 → 예산표 배정

축제 부스 배치(부서)는 그대로 두고, 같은 배치 엔진을 쓰던 예산 테트리스(머리 퍼즐)를 칸 하나씩 추리하는 논리 퍼즐로 바꿔요. 참고: LinkedIn Queens(색 구역마다 하나, 가로·세로마다 하나, 붙으면 안 됨 — 규칙 세 줄로 누구나 시작하지만 큰 판은 꽤 어려움), Star Battle(같은 규칙의 퍼즐 잡지판, 난이도 단계가 촘촘).

축제 부스 배치와의 차이 — 부스 배치는 모양 있는 블록을 끼워 넣는 공간 퍼즐, 예산표 배정은 칸마다 ‘된다/안 된다’를 따지는 추리 퍼즐이에요. 같은 판 모양(격자)이지만 손이 하는 일이 달라요.

8×8 · 큰 색 구역이 많아 처음 몇 칸이 바로 안 보여요.
↶ 되돌리기💡 힌트✓ 제출

③ 상 4 · 8×8 — 실제 생성 판. ‘두 구역이 같은 두 줄에 갇힘’ 같은 한 단계 깊은 추리가 필요해요.

규칙

  • n×n 예산표: 가로 = 달, 세로 = 팀, 칸 색 = 재원 구역(국비·시비·구비·기금…). 구역 수 = n.
  • 📌 사업을 n개 놓아요: 달마다 1개, 팀마다 1개, 색 구역마다 1개, 사업끼리 상하좌우·대각선으로 붙으면 안 됨.
  • 정답은 반드시 하나(생성기 확인). 제출 시 📌만 판정, ✕는 메모.

30레벨 사다리

레벨하중상
1~105×5, 1칸 구역 있음(시작점)7×78×8
11~206×67×7, 1칸 구역 없음8×8, 구역 모양 길쭉(줄 묶음 추리)
21~306×6, 큰 구역 많음8×8 입문9×9, 2구역 짝 추리 필수

데이터

level = { n:6, reg:[[2,0,1,1,1,1], ...],          // 칸별 재원 구역 번호
  rows:["생활보장","조사관리","노인복지",...], cols:["1월",...,"6월"],
  regName:["기금","시비","국비","특교","구비","민간"],
  witness:{ pins:[1,4,2,5,3,0] } }                  // 팀(줄)마다 📌 달(열)
draft = { m:[[0,1,2,0,...],...] }                   // 0 빈칸 · 1 ✕ · 2 📌

생성·풀이기·난이도

  • 생성: 붙지 않는 무작위 순열(정답) → 정답 칸마다 구역 씨앗 → 무작위로 구역을 키워 판 채우기 → 백트래킹 풀이기로 정답 개수(2개 찾으면 중단) → 1개일 때만.
  • 난이도: 논리 풀이기가 추측 없이 푸는 데 쓴 기술 수준. ① 남은 칸이 하나뿐인 줄·열·구역 ② 📌 주변·같은 줄 지우기 ③ 구역이 한 줄 안에만 있으면 그 줄의 다른 칸 지우기 ④ k개 구역이 k개 줄 안에 갇힘(짝 추리) ⑤ 가정해 보고 모순이면 지우기(1단계). 점수 = 판 크기 × 1 + 각 기술 사용 횟수 × 가중치(1·1·2·4·6). ⑤가 필요한 판은 상 21~30에만.
  • build(): 단계별(판 크기·필요 기술) 후보군에서 골라 사다리 유지.

화면

  • 칸 탭 순환 빈칸 → ✕ → 📌 → 빈칸. 길게 누른 채 끌면 지나간 칸에 ✕ 여러 개(Queens의 끌어 지우기).
  • 구역 경계는 굵은 선 + 색, 색약 배려로 구역마다 무늬(점·빗금) 선택 가능(설정 ‘색 대비 높이기’와 연결).
  • 📌 놓을 때 도장 쾅 소리, 규칙 어긴 📌는 즉시 빨간 테두리. 9×9도 칸 30px로 375px 폭 안.
  • 예산 맛: 다 놓으면 아래에 “상반기 집행 계획: 1월 노인복지(국비) …” 요약 한 줄이 뜸.

힌트·별·스토리

  • 힌트 1: 지금 쓸 수 있는 기술 이름과 위치(“기금 구역은 칸이 하나예요”) · 힌트 2: 확실한 칸 하나 📌 · 힌트 3: 정답.
  • 별: 완료 · 힌트 없이 · 틀린 제출 0.
  • 스토리 예산 업무 대사(week.js “상반기 예산표에 사업을 넣어 주세요”)는 그대로 맞음. 다음 날 결과 “예산표 그대로 상반기 집행 시작”도 유지.
