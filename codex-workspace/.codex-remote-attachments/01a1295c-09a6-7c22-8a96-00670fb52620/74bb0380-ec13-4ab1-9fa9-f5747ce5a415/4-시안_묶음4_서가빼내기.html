묶음 4 · 시안과 구현 계획

상자 밀기 묶음 → 서가 빼내기

구호물자 창고 정리(부서)는 상자 밀기 그대로 두고, 같은 엔진·같은 생성기였던 서고 정리(머리 퍼즐 · 선택 업무)를 바꿔요. 참고: Unblock Me · Rush Hour(가로·세로로만 미끄러지는 블록을 움직여 목표 블록을 빼냄 — 판이 작아도 최소 수가 20수 넘는 판이 있을 만큼 깊음, 모바일 캐주얼 장기 흥행작).

이야기: 서고 통로에 이동식 서가 수레가 빽빽이 서 있어요. 수레는 놓인 방향으로만 앞뒤로 밀려요. 빨간 이관 상자 수레를 서고 문 밖으로 빼내면 성공.

불법주차 견인과의 차이 — 견인은 차를 한 번 누르면 화살표 방향으로 끝까지 빠져나가고, 차를 빼는 순서만 정하면 돼요. 서가 빼내기는 수레를 앞뒤로 조금씩 옮기며 길을 만들고, 어떤 수레는 여러 번 왔다 갔다 해야 해요(되돌리는 계획). 시안을 보시고 그래도 비슷해 보이면 아래 대안(하노이 탑식)으로 갑니다.

◀ 지도대안 · 서가 옮기기하노이 탑식중
왼쪽 수레의 상자를 오른쪽으로. 큰(오래된) 상자는 작은 상자 위에 못 올려요.
2019202120232025
하: 상자 3개(7수) · 중: 4개(15수) + 금지 칸 · 상: 수레 4대·상자 5~6개·이동 제한
대안의 약점: 규칙이 단순해 30레벨 사다리를 만들기 어렵고, 재활용 선별장(쌓아 옮기기)과 손이 비슷해요.

③ 대안 — 서가 빼내기가 불법주차와 겹쳐 보일 때만.

규칙

  • 6×6 서고(상 일부 7×7). 수레는 길이 2 또는 3, 가로 수레는 좌우로만·세로 수레는 위아래로만 미끄러짐. 다른 수레·벽을 넘을 수 없음.
  • 빨간 이관 상자 수레(가로 2칸)는 문이 있는 줄에 있고, 오른쪽 문 밖으로 나가면 성공.
  • ‘이동’ = 수레 하나를 잡아 놓기 1번(여러 칸 미끄러져도 1수). 별 3번째 = 최소 수 + 여유 안.
  • 상 21~: 고정 책장(움직이지 않는 칸), 상 26~: 문이 위·아래에도 있고 상자가 2개(두 상자 모두 빼야 함).

30레벨 사다리 (최소 수 기준)

레벨하중상
1~10수레 3~5, 2~5수수레 6~8, 8~12수수레 9~11, 15~20수
11~20수레 5~6, 5~8수12~16수, 길이 3 수레 많음20~26수
21~308~10수16~20수 + 고정 책장26수 이상 / 상자 2개 · 문 2곳

데이터·생성·풀이기

level = { w:6, h:6, door:{side:"R", row:2},
  carts:[{id:"X",x:1,y:2,len:2,h:1,goal:true}, {id:"A",x:3,y:0,len:3,h:0}, ...],
  walls:[[5,5]],                 // 고정 책장 (상 21~)
  par:7, min:5,
  witness:{ moves:[["A",-1],["C",+1],["X",+4]] } }    // [수레, 칸 이동]
draft = { moves:[["A",-1], ...] }
  • 생성: 무작위 배치(이관 상자 줄에는 가로 수레 금지) → 너비 우선 탐색으로 최소 수(6×6은 상태 수가 작아 수십 ms) → 풀리고 최소 수가 단계 범위 안이면 채택. 상 상위 판은 ‘최소 수가 가장 긴 판’ 찾기(풀린 상태에서 거꾸로 가장 먼 상태를 고르는 방법)로 26수 이상 확보.
  • 난이도 점수 = 최소 수 × 1 + 다른 수레를 움직인 횟수가 3번 이상인 수레 수 × 1.5 + 탐색 상태 수 log × 0.5.
  • 판정: draft의 이동을 차례로 적용(겹침 검사) → 상자가 문 밖이면 valid, metric = 이동 수.
  • 코드 정리: sokobanModule·sokoGen은 구호물자 창고 전용으로 남김.

화면

  • 수레를 끌면 칸 단위로 스냅해 미끄러짐(막히는 곳까지만), 끌기 어려우면 수레를 탭한 뒤 ◀▶/▲▼ 버튼.
  • 수레 그림: 가로 = 나무 서가, 세로 = 철제 서가, 이관 상자 = 빨간 상자. 문 밖으로 빠지면 상자가 복도로 굴러가는 연출.
  • 되돌리기 무제한, 이동 수 표시 “이동 6 · 목표 7”.

힌트·별·스토리

  • 힌트 1: 지금 이관 상자를 막는 수레들 표시 · 힌트 2: 정답의 다음 한 수 · 힌트 3: 정답 재생.
  • 별: 완료 · 힌트 없이 · 이동 ≤ par(최소 + 하 3 / 중 2 / 상 2).
  • 선택 업무(서고) 대사 “서고 정리 좀 도와줘요”는 그대로. 다음 날 결과 문구 그대로 사용 가능.
