3개 맞추기 묶음 → 놀이터 그물 풀기

기록물 철하기(트리플 매치)는 기록관리팀 업무와 딱 맞아 그대로 두고, 같은 구조(드러난 것 집기 → 받침대 → 3개면 사라짐)인 노후 놀이터 해체를 끌어서 푸는 공간 퍼즐로 바꿔요. 참고: Untangle(점을 끌어 선이 안 겹치게 — 규칙 한 줄, 손가락 조작에 최적), Tangle Master 3D(모바일 캐주얼 대표작, 로프 색·고정점으로 단계 상승).

이야기: 공원녹지과가 낡은 놀이터 오르기 그물을 정비하는데 로프가 엉켰어요. 매듭(동그라미)을 옮겨 로프끼리 하나도 안 겹치게 해야 새 그물로 교체할 수 있어요.

규칙

  • 매듭 = 점, 로프 = 두 매듭을 잇는 곧은 선. 매듭을 판 안 아무 곳으로 끌어 옮김(다른 매듭 위에는 못 놓음).
  • 성공: 어떤 두 로프도 서로 교차하지 않음(같은 매듭에서 만나는 건 괜찮음) + 장치 조건(고정 기둥 그대로, 로프 길이 ≤ 한계).
  • ‘옮긴 횟수’ = 매듭을 집어 놓은 횟수(같은 매듭 연속 이동은 1번). 별 3번째 목표.

데이터·생성

level = { w:240, h:240,
  nodes:[[169,26],[55,179],...],     // 시작 위치
  edges:[[0,1],[0,7],...],
  pins:[3,7],                        // 고정 기둥 매듭 (없으면 [])
  maxLen:110,                        // 로프 길이 한계 (없으면 null)
  par:8,                             // 별 3번째: 옮긴 횟수 목표
  witness:{ nodes:[[210,120],...] } }   // 겹침 없는 정답 위치 하나
draft = { nodes:[[x,y],...], moves:3 }
  • 생성: ① 겹침 없는 그물을 먼저 만듦 — 판에 점 무작위 → 들로네 삼각분할 → 일부 로프를 빼서 매듭당 로프 2~4개(사다리·바퀴·격자 모양 틀 섞기). 이 위치가 정답(witness). ② 기둥 매듭은 정답 위치에 고정, 길이 한계 = 정답 로프 최장 길이 × 1.1~1.25. ③ 나머지 매듭을 흩어 놓되 겹침 수가 단계 목표 이상이 되게.
  • par: ‘흩어 놓은 매듭 중 정답 근처에 있지 않은 것’의 수 + 여유(하 +3, 중 +2, 상 +1). 실제 정답 위치로 옮기면 반드시 그 횟수 안에 풀림.
  • 난이도 점수 = 매듭 수 × 1 + 처음 겹침 수 × 0.15 + 기둥 × 2 + 길이 한계 빠듯함 × 3. 정답이 하나일 필요는 없음(겹침 없는 배치면 무엇이든 정답).
  • 판정은 선분 교차 검사(로프 20줄이면 190쌍, 즉시)와 길이 검사뿐 — 풀이기가 필요 없음.

화면

  • SVG 한 장: 로프(선)·매듭(원). 포인터 끌기로 매듭 이동(놓기 전에도 겹침 수 실시간 갱신), 손가락에 가리지 않게 끄는 중인 매듭은 살짝 위에 표시.
  • 겹친 로프 빨강, 겹침 0인 로프 초록, 길이 넘은 로프 점선. 🔩 기둥은 굵은 테두리 + 나사 그림.
  • 되돌리기 = 마지막 이동 취소. 판 크기는 화면 폭에 맞춰 늘고 줄며(viewBox) 매듭 지름 24px 이상.
  • 완료 연출: 낡은 로프가 초록 새 로프로 차례로 바뀌고 아이가 그물에 올라가는 픽셀 그림 한 장.

힌트·별·부서 연결

  • 힌트 1: 겹침이 가장 많은 매듭 반짝 · 힌트 2: 매듭 하나를 정답 위치로 옮김 · 힌트 3: 정답 배치.
  • 별: 완료 · 힌트 없이 · 옮긴 횟수 ≤ par.
  • 공원녹지과 우호도·기념 소품·소식지 문구는 그대로. 부서 안내도의 ‘노후 놀이터 해체’ 이름은 ‘놀이터 그물 정비’로 바꿈.
